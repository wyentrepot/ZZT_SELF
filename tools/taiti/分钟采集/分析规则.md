# 分钟采集（MCLT）分析规则 — 权威口径

> 来源：2026-09-20 安徽 184 表分钟采集漏报排查（三端：侦听台 / CCO / 页面）。
> 本文件是分析口径的权威参照；`README.md` 是工具说明，技能 SKILL.md 是执行步骤。
> 如分析结论与最新日志实测冲突，以最新实测为准并更新本文件。

## 1. 业务流与三端

```
STA ──11E4 主动上报(0x00E4)──► CCO ──06F230 组帧上送──► 集中器(页面)
  │                                ▲
  └──11E3 补抄下发(0x00E3)──────────┘（STA 以 11E3 响应回数据）
```

| 端 | 文件 | 能证明什么 |
| --- | --- | --- |
| 侦听台（空中） | `[ N][HH:MM:SS.mmm]7E ...` | STA 是否真主动上报（11E4）、补抄请求/响应（11E3）是否在空中出现；**唯一时间基准** |
| CCO 串口日志 | `[YYYYMMDD-HH:MM:SS:mmm]...` | CCO 是否收 11E4、是否下发/收到 11E3、是否组 06F230、丢弃/拒绝告警 |
| 页面 xlsx | 冻结周期→表地址 | 集中器实收口径（导出快照，只含导出时刻前已上报数据） |

**业务流**：集中器下发 11-F231 任务/11-F232 档案 → CCO 配置下发 0x00E2 →
STA 在冻结周期结束边界主动上报 0x00E4（=11E4，携带上一周期冻结）→ CCO 校验
（任务/档案/冻结时标/去重）入 rptlist → 未上报成功 CCO 补抄 0x00E3（=11E3，
带上一周期冻结）→ 有效数据组 06-F230 上送集中器。
补抄窗口（现场固件）：下一周期最后一分钟 :00 起；单表同冻结 ≤3 次尝试
（500ms×3 连发）。

## 2. 关键帧特征（解析依据）

- **11E4（主动上报）**：应用帧 `11e4`；STA 在帧内为 `XXXX 50 00 00 66`
  （显示地址 66000050xxxx 反转）；**冻结 6B BCD 在 STA 后第 2 字节起**。
- **11E3（补抄，双向）**：应用帧 `11e3`；STA 同上；**冻结在 STA 后第 1 字节起**；
  下行请求 bytes4-5=`0105`、上行响应 bytes4-5=`c115`；
  **响应回显请求的序号（bytes6-7）**→ 可 100% 精确配对请求↔响应（本 CCO 固件行为）。
- **06F230（CCO→集中器上送）**：日志行含 `06201c01`，冻结 5B BCD（分时日月年，无秒）
  在 `0200` 后；**只出现在 CCO 日志，不在侦听台 7E 空中捕获里**（别去 7E 搜它）。
- **冻结 BCD**：秒分时日月年，必须 BCD 解码（`int("20",16)` 是 32 不是 20）。

## 3. 踩坑记录（解析/判定前必读）

1. **06F230 不在侦听台 7E 捕获里**（走 CCO↔集中器链路），7E 里搜不到是正常。
2. **CCO 日志行被截断**（约前 30B=60 hex）：11E4/06F230 只能看到 STA+冻结起始。
   存在性可作正证据，**缺失不可作反证据**（还有丢行/抽样）。
3. **CCO 日志 06F230 打印是子集**（每周期 36~74 条 vs 页面实收 162~181）：
   用"该表有没有 06F230 打印"判"没上送"前，先做抽样概率核算。
4. **7E hex 带空格**：必须去空格后搜（`11 E4` 亦然）；大小写可能不匹配。
5. **BCD 不是 hex**：`int("20",16)=32` 会把日期 20 号判非法，必须 BCD 解码。
6. **帧内 STA 反转**：显示地址 66000050xxxx 在帧内为 `XXXX 50 00 00 66`；
   用正则 `([0-9a-f]{4})50000066` 提取最稳，别用 `find("0001")`（误命中帧头）。
7. **11E4/11E3/06F230 冻结偏移不同**：11E4 在 STA+2B、11E3 在 STA+1B、
   06F230 在 `0200` 后 5B（无秒）；统一函数会全军覆没。
8. **页面 xlsx 日期 `2026/9/20` 不补零**，须先归一化。
9. **xlsx 只是导出快照**：只含导出时刻前上报的数据；缺报判定要结合三端。
10. **"drop stale"告警不带 MAC**：无法直接看丢谁；用"该表空中上报到达时刻 vs
    CCO 处理时刻/边界"做时序关联（本工具 miss 命令按当前处理帧近似关联）。
11. **时钟语义**：
    - 侦听台捕获时刻 = 空中真实时间，**唯一时间基准**；
    - CCO 日志括号时间 = 串口宿主打印时刻，比空中晚 **~1-3s**（洪峰 2~6s，最长 10s+），
      这是**打印延迟不是 RTC 偏差**；
    - CCO RTC 由集中器每 5 分钟校时（`gw13762.c rx_13762_query_time`），≈ 真实时间；
    - 边界竞态反推 CCO RTC 相对真实时间滞后 ~0.5~2s（即模型 cco_offset_s=-2 的方向与量级）。
12. **补抄响应 "rejected result:2" 会误导**：10:44 被拒的响应其实是 result:0 +
    ssn/冻结回显正确；直接机制是 **500ms×3 连发耗尽后 clt=UNCLT，响应晚到
    ~1-2s 触发 clt != COLLECTING 拒绝**（重试期间到达的旧 ssn 响应亦被拒）。
    只看日志 result 字段会误判成"STA 采集失败"。

## 4. 判定口径

1. **jitter**：11E4 携带冻结=X 的表在 边界 X+period（15min）±几秒内上报。
   实测（2026-09-20，10:15 周期 n=177 首达）：min −1.25s / P50 +1.44s / P95 +3.45s /
   max +8.17s，±3s 内 85.3%，16.4% 提前到达。STA 行为与设计一致（边界驱动上报）。
2. **边界竞态漏报（10:15 缺 22 块主因）**：页面缺失表全部有空中 11E4 且
   jitter ≤ +0.33s（最早到达者）；现场固件冻结匹配口径 = 上报冻结 == 上一周期起点
   （无容差），CCO RTC 跨边界前处理的早达上报被判 stale → drop → 不入 rptlist →
   不组 06F230。判定条件：`页面缺失 ∧ 空中11E4 ∧ CCO已收 ∧ (stale丢 ∨ 无06F230)`。
3. **补抄救不回（次因）**：11E3 响应延迟实测 P50≈1.1s、均值≈2.0s、P95≈6.4s
   （CCO 视角，n≈316）；空中 STA 响应其实 ~50ms 级，大头是 CCO 发送队列 ~1.1s；
   500ms×3 连发在 1.0s 内耗尽 → 晚到响应全被拒 → 补抄失败。
4. **背景漏报（9:45/10:00 各缺 3-4 块）**：既未主动上报也未补抄成功的少量表，
   常规小缺口，非边界竞态。

### 6.2 非降本 STA 烧录 — ❌ 未成（fail 在进 bootloader 之前）

- 工作台：`POST /api/ai/v2/module-actions`（`mapping_id=sta-main`）→ 会话 `ms-533e7eae8ca4` 正常打开；
  `POST /api/ai/v2/flash-jobs` 提交 iap 包，`firmware_roots` 已通过 `WORKBENCH_AI_FIRMWARE_ROOTS` 放行。
- 失败原因：`Bootloader prompt was not detected.`
- 证据（会话日志）：发 `reboot` + Ctrl-C 后，COM18 只持续输出运行日志
  （`mac_recv_task.c` / `phy_hplc.c` / `rx beacon`），**没有任何 `[image /]#` 或 shell 提示**；
  时间戳连续（1024874→1037875 ms），说明模块没重启。
- 排查：该 CH344 四通道的另外三口（COM16/17/19）与 COM13 临时挂到桥上探测，
  **全部 0 字节静默**；COM27(listener) 是 1376.2 总线抓包，不是控制台。
- 结论：**COM18 是纯日志口**，本板没有可用的 bootloader shell 入口；IAP 需要
  “上电/复位窗口”或另一个控制台口。次日需确认：板上复位按钮/工装是否可远程复位，
  或该板把 shell 引到哪个物理口（旧板是 COM9 且 `reboot` 有效）。

## 一、现状诊断：为什么"丑"

现有 `apps/workbench/static/pages/simcon/simcon.html` 是**五层垂直堆叠**：

```
顶栏(面包屑+5个下拉+2按钮) → 四列工作区(300|236|256|1fr) → 内置应答条
→ 结果面板(4页签, max-height 42%) → 收发记录(240px)
```

问题不在配色（tokens-v2 本身达标），在**信息架构**：

| # | 问题 | 具体表现 |
|---|------|---------|
| 1 | 一屏塞下全部 10 组功能 | 参数区、帧预览被挤到只剩 ~40% 高度；真正干活的地方反而最小 |
| 2 | 没有导航层级 | 所有功能平铺，第一眼找不到"我在哪、下一步干什么" |
| 3 | 折叠能力只有两处 | 结果面板▾、收发记录可折，主工作区四列焊死不可调 |
| 4 | 深化应用（并发抄表）挤在 300px 窄列 | 模块表格在窄列里横向局促，向导式流程（①档案→②下发→③统计）被压成三行按钮 |
| 5 | 顶栏职责过载 | 串口会话参数（5 下拉+2 按钮）与构帧操作混在一行，认知负担大 |

## 二、设计原则：软件骨架恒定，工作区按任务切换

像桌面软件（SecureCRT / Modbus Poll / VS Code）那样，把界面拆成**三条恒定骨架 + 一个可切换工作区**：

1. **一屏一事**：10 组功能按任务切成 4 个工作区，每个工作区只回答一个任务；
2. **骨架恒定**：菜单栏（全局动作）、左侧栏（功能导航）、底部面板（会话示波器）、状态栏（全局状态）位置永不移动，用户形成肌肉记忆；
3. **全局资产下沉**：收发记录是所有工作区共用的"示波器"，放底部 Dock 全局可见——在并发抄表页下发，也能立刻看到帧日志；
4. **密度与层次**：沿用 tokens-v2 四级实心表面 + 发丝描边 + 等宽帧字体，两套主题（墨夜/晴昼）全兼容。

## 四、四个工作区

```
┌─────────────────────────────── 菜单栏 ───────────────────────────────┐
│ SC·模拟集中器   会话  数据  视图  帮助            [●COM3 已连接]      │
├──────────┬──────────────────────────────────────────────────────────┤
│ 侧栏      │  工作区（Alt+1~4 切换）                                   │
│ ┌──────┐ │  ① 构帧下发    AFN列 │ Fn列 │ 参数+帧预览+下发            │
│ │连接卡 │ │  ② 并发抄表    三步向导：①档案 → ②勾选下发 → ③周期统计     │
│ └──────┘ │  ③ 数据观测    页签：配对/抄读汇总/并发任务/主动上报        │
│ ▸构帧下发 │  ④ 会话设置    串口参数 + 内置应答 + Profile               │
│ ▸并发抄表 │                                                          │
│ ▸数据观测 ├──────────────────────────────────────────────────────────┤
│ ▸会话设置 │  底部 Dock（全局）：[收发记录|最近配对●2]  ← 可折叠/拖高    │
│ [主题][⟨] ├──────────────────────────────────────────────────────────┤
└──────────┴──────────────────────────────────────────────────────────┘
 状态栏：●COM3 · 9600 E · anhui ｜ TX 128 RX 126 ｜ 最后帧 22:14:03 ｜ 假数据 demo
```

1. **① 构帧下发**（高频主战场）：AFN｜Fn｜参数三列占满全高；帧预览不再被压扁；响应表格作为第 3 列底部可折叠分区（分页型 Fn 自动展开）。
2. **② 并发抄表**（业务向导）：顶部三步进度指示（① 查档案 10H-F2 → ② 勾选下发 F1H-F1 → ③ 周期统计），档案表全宽铺开（勾选/信号品质/中继级别/在网一屏尽收），统计周期与统计表右栏或下方。
3. **③ 数据观测**（回看）：收发配对 / 抄读汇总 / 并发任务 / 主动上报 四页签，全宽表格 + 分桶统计，轮询逻辑随页签启停（与现逻辑一致）。
4. **④ 会话设置**（低频）：串口参数卡（含"无端口自动选可用串口"提示）+ 内置应答配置 + Profile。

## 五、全局骨架规格

### 菜单栏（新增，软件感的核心）
| 菜单 | 项 |
|---|---|
| 会话 | 打开串口 / 关闭串口 / 自动选择串口（9600·E） / 重新加载端口 |
| 数据 | 导出档案 Excel / 响应快照查询 / 06H 上报历史 |
| 视图 | ☑ 折叠侧栏 Ctrl+B / 底部面板 / 切换主题 / 收发记录过滤(全部/发送/接收) |
| 帮助 | 接口文档 / 功能清单 / 关于 Demo（假数据声明） |

- 左侧品牌字 + 菜单文字项，右侧常驻**连接状态徽标**；点击展开下拉，Esc/点击空白关闭；菜单项带快捷键标注。

### 左侧栏（可收缩，用户点名）
- 展开态 220px：连接卡（端口/参数/状态灯/打开关闭按钮）+ 4 个工作区导航（图标+文字）+ 底部（主题切换、折叠按钮）；
- 收缩态 52px 图标栏：悬停 tooltip 显示名称，连接卡缩为一颗状态灯；
- 收缩方式：底部 `⟨` 按钮 / 菜单「视图」/ **Ctrl+B**。

### 底部 Dock（收发记录 + 最近配对）
- 两页签：**收发记录**（全局帧日志，全部/发送/接收过滤 + TX/RX 计数徽标）、**最近配对**（每次下发自动追加"下发帧↔应答帧"卡片，页签带未读计数）；
- 可折叠成 30px 细条、上边缘**拖拽调高**、双击边条折叠；
- 下发动作跨工作区联动：在并发抄表页下发，Dock 同样出帧。

### 状态栏
`●COM3 · 9600 E · anhui ｜ TX n RX n ｜ 最后帧 hh:mm:ss ｜ 提示区`——全局状态一眼读，替代旧顶栏过载。

## 六、交互与快捷键

| 操作 | 行为 |
|---|---|
| Alt+1~4 | 切换工作区（侧栏同步高亮） |
| Ctrl+B | 折叠/展开侧栏 |
| 下发成功 | 状态栏提示 + Dock「最近配对」徽标 +1 |
| 工作区切换 | 各自状态保留（AFN/Fn 选择、勾选集、页签） |
| 菜单/下拉 | 点击展开、Esc/点空白关闭、方向键可巡游 |

## 七、落地路径（评审通过后）

1. **不换骨架**：`simcon.html` 仍是外壳 iframe 子页，P0-4 防主题闪跳脚本、`wb-theme-change` 跟随逻辑原样保留；两套主题走 tokens-v2 变量，Demo 内联 token 即为预演。
2. **不改 API**：`/api/simcon/*` 全部契约不动；`simcon.js` 各 render 函数（renderAfn/renderDeepPanel/switchPanel…）按工作区归位，事件绑定与轮询逻辑平移。
3. **分两步**：先搬"工作区化"（纯 HTML/CSS 重排 + JS 挂载点改名），再加菜单栏/快捷键/Dock 拖拽；每步独立可回归（工具页双副本同步、commit 后进一键启动）。

## 八、Demo 使用说明

- 文件：`ui-demo/simcon-ui-demo-v3.html`，双击即开，**全部为假数据**（状态栏右侧有声明）；
- 建议体验：切工作区 → 折叠侧栏（Ctrl+B）→ 菜单「会话/视图」→ 拖拽/折叠底部 Dock → 勾选模块看"已选"计数 → 点「下发」看 Dock 联动 → 菜单「视图」切主题。

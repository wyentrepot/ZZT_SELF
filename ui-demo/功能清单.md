## 上一版 Demo 的功能缺失（已确认）

| 缺失项 | 严重度 | 说明 |
|---|---|---|
| 模块日志 · 串口发送框 | **严重** | 用户点名；含自动补换行、Enter 发送等 |
| 模块日志 · 对照解析页签 | **严重** | 整页丢失：来源二选一、行号漂移统计、事件↔日志双向绑定 |
| 模块日志 · 动态会话页 | 高 | 多页面增删、会话状态点 |
| 侦听台 · 分钟采集分析 | **严重** | 用户点名；整视图丢失 |
| 侦听台 · 任务配置统计 | 高 | 整视图丢失 |
| 侦听台 · 网络承载评估 | 高 | 整视图丢失（含 canvas 趋势图） |
| 侦听台 · 全局 NID 筛选 | **严重** | 用户点名「NID 锁定」；含时间范围 + 筛选 chips |
| 侦听台 · 新版帧浏览 | 高 | 三列布局 + NID 筛选列 |
| 场景脚本页 | **严重** | 整个页面缺失（9 页做成 8 页） |
| 串口配置真实形态 | **严重** | 做成「串口档案」，实际是**四槽 Profile 保存与一键应用** |
| 验证工作台跳过项 | 中 | 做成跳过烧录/监控/激励/比对，实际是跳过烧录/激励/反馈 |
| 验证工作台固件信息 | 中 | 缺固件版本 / commit / 日志目录 |
| 取消 Run | 中 | 缺失 |
| 证据下钻 | 中 | 缺失 |
| 主题切换 | 中 | 缺失（4 主题） |
| 页面命名 | 低 | 「协议字典」误作「报文字典」、「工作台状态」误作「维护」 |

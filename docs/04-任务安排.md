# 侦听台改造项目任务安排

> 本文只定义任务 1～5、状态、优先级、阻塞项与验收出口。需求和设计正文分别引用[总需求](02-总需求.md)与[骨架设计](03-骨架设计.md)。

## 1. 状态口径

- `已完成`：验收出口有可复现证据。
- `进行中`：已有实际变更，尚未满足全部出口。
- `待开始`：尚未进入实现。
- `阻塞`：缺少外部决策、硬件、协议结论或依赖。

## 2. 总览

| 任务 | 优先级 | 状态 | 目标出口 |
|---|---:|---|---|
| 任务 1：冻结验证契约 | P0 | 进行中 | 领域模型、状态机、用例包和 API 契约通过评审并有单测 |
| 任务 2：打通最小证据闭环 | P0 | 进行中 | 安徽分钟采集固定用例可执行并生成可下钻报告 |

## 3. 任务明细

### 任务 1：冻结验证契约

- 范围：CasePackage、Run、Evidence、AssertionResult、Report、Artifact、SourceAdapter、资源租约。
- 当前：设计资料已有多个版本，需以[骨架设计](03-骨架设计.md)为唯一口径落实代码与测试。
- 阻塞：无。
- 验收出口：模型序列化、状态迁移、用例指纹、证据追加/冻结、资源互斥均有自动化测试。

### 任务 2：打通最小证据闭环

- 范围：首个安徽分钟采集用例、证据窗口、结构化断言、报告归档、基础 API。
- 当前：帧结构手册、代码差异分析和实施计划已存在；端到端实现尚需以仓库测试确认。
- 阻塞：E2/E3/E4 部分协议知识点待确认，首版只使用已确认字段并显式标记未知项。
- 验收出口：固定输入结果一致；缺失来源为 `inconclusive`；报告可追到原始帧/日志。

### 任务 3：接入三源与迁移资产

- 范围：侦听台帧、loghooks 事件、模拟集中器步骤接入；GW-CASS 用例语义与资产迁移。
- 当前：三模块已有独立能力和历史设计，尚未全部适配统一 Evidence 契约。
- 阻塞：真实串口和设备测试需要 Windows 硬件环境。
- 验收出口：一个 Run 同时消费三源证据；资源冲突可预测；迁移用例与旧工具结果一致。

### 任务 4：完善统一工作台与交付

- 范围：验证 UI、运行恢复、证据下钻、错误降级、一键启动和打包。
- 当前：`apps/workbench` 正在开发，listener/module_log 已有独立入口；统一交付仍需系统验收。
- 阻塞：打包依赖 .NET DLL、静态资源及 Windows 环境联合验证。
- 验收出口：干净 Windows 环境可启动；刷新后恢复 Run；DLL/串口缺失不阻断无关能力；发布物无开发机路径。

### 任务 5：协议专项与质量加固

- 范围：OAD/OI 覆盖、分钟采集待确认项、大文件性能、异常恢复、回归与发布检查。
- 当前：历史问题清单和分析结果已归档。
- 阻塞：协议口径需产品或协议负责人确认。
- 验收出口：待确认项有结论与测试；性能基线可复现；异常恢复、长时间运行和发布冒烟通过。

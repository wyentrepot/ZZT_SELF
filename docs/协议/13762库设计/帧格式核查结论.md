## 结论一：权威帧格式 = 单 68 信封

1376.2 采用 GB/T 18657.1 FT1.2 异步式传输帧：

```
68H | L(2B) | C(1B) | 用户数据(L1) | CS(1B) | 16H
       └长度┘ └控制域┘ └──用户数据区──┘ └校验┘ └结束┘
```

用户数据内部：`R(信息域) | A(地址域) | AFN | 应用数据`。

- 三份文档均只出现一个 68H 起始符 + 一个 16H 结束符，**不存在"双 68 信封"结构**。
- Q/GDW 10376.2—2019 取代 1376.2—2013，但链路层帧格式结构完全相同。
- 现有 adapter_10376 的双 68 信封（68|L|68|AFN|SEQ|RTUA|MSAA|PW|...）**与权威标准不符**，应视为其他形态。

## 结论二：关键域精确定义

| 域 | 定义 |
|---|---|
| **C 控制域**（1B） | D7=DIR（0=集中器下行，1=模块上行）；D6=PRM（0=从动站，1=启动站）；D5~D0=通信方式（1=集中式路由载波，2=分布式路由载波，3=HPLC/宽带，10=微功率无线，20=以太网，其余备用） |
| **L 长度域**（2B BIN） | L = 用户数据长度 L1 + 6；L ≤ 65535；每帧接收字符数 = L1 + 6 |
| **R 信息域** | 下行 6B = 路由标识/中继级别(0~15)/通信模块标识(0主节点·1从节点)/信道标识/纠错编码/预计应答字节数/速率(单位+数值)/报文序列号(0~255)；上行 6B 含电能表通道特征、实测相线、末级信号品质、事件标志、报文序列号 |
| **A 地址域** | 源地址 A1(6B BCD) + 中继地址 A2(6×中继级别 BCD) + 目的地址 A3(6B BCD)；R 中"通信模块标识"=0 时**无地址域**；广播时 A3=999999999999H |
| **CS 校验和** | 控制域 C + 用户数据区所有字节的 8 位算术和（模 256，忽略进位） |

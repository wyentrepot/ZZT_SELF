# 大体积国网日志文件解析实施计划

**目标：** 在本地 Windows 网页工具中加载数百 MB 文本日志，流式建立帧索引，分页查看帧摘要，并在点击单帧时按需展示完整 DLL 解析结果。

**架构：** 后端以二进制逐行读取日志，只扫描源文件一次；每行提取时间、序号和 `7E ... 7E` 报文，调用 `GwHPLCAnalysis.dll` 生成摘要，并写入当前会话的 SQLite 索引。浏览器只请求状态、分页摘要和选中帧详情，不持有整份文件。索引任务在单独线程运行，避免阻塞网页请求，也避免并发调用 DLL。

**技术栈：** FastAPI、Python.NET、SQLite、原生 HTML/CSS/JavaScript、unittest。

---

### 任务 1：建立受限测试样本

- 新增 `scripts/extract_log_sample.ps1`，按行数和最大字节数截取，不读取完整源文件。
- 仅运行一次脚本，从用户指定的 303,333,040 字节日志生成小型开发样本。
- 后续测试和开发只访问小样本。

### 任务 2：先用测试定义流式日志索引

- 新增 `hplc_web/tests/test_log_service.py`。
- 覆盖日志行解析、多个帧提取、SQLite 分页、状态统计、按 ID 获取详情、非法路径和取消旧任务。
- 使用假解析器验证“摘要在索引阶段生成、完整解析只在点击详情时发生”。
- 运行新测试并确认在实现前失败。

### 任务 3：实现文件索引服务

- 新增 `hplc_web/log_service.py`。
- 二进制逐行读取并以 UTF-8/GB18030 容错解码。
- 将帧序号、日志时间、长度、摘要、原始十六进制写入 SQLite。
- 提供后台加载、进度、分页、筛选和按需详情方法。
- 限制单页数量，避免大结果进入内存或浏览器。

### 任务 4：扩展 FastAPI 文件接口

- 修改 `hplc_web/app.py`，注入日志服务。
- 新增加载、状态、分页帧列表和单帧详情 API。
- 对不存在文件、越界分页、忙碌状态和解析异常返回明确错误。
- 保留现有单帧解析接口。

### 任务 5：重做本地网页

- 修改 `hplc_web/static/index.html`、`styles.css`、`app.js`。
- 顶部操作区：日志路径、加载按钮、进度、状态与筛选。
- 底部主区：左侧分页帧摘要表，右侧选中帧详情面板。
- 详情面板展示日志元数据、解析步骤/层级、完整 JSON 和原始报文。
- 保留单帧调试入口，避免影响既有使用方式。

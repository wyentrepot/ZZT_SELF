  false；项目源码不安装到个人 Codex 目录；
- 仅提供 `status`、`observe`、`wait`、`artifact`、`listener-schema`、
  `frame-detail` 六命令；
- Token 唯一来源是 `WORKBENCH_AI_TOKEN`，不得出现 token CLI 参数、位置参数、
  配置文件值、URL userinfo 或明文输出；
- `observe` 默认 dry-run，零 HTTP、零 operation；只有明确 `--execute` 才可
  `POST /api/ai/v1/observations`；目标只能是既有 module session 或既有 listener
  index/capture；
- 客户端不得提供、隐藏或转发 ensure/start/stop/send/flash/烧录、串口打开、
  operation cancel、产品文件读取或目录扫描；历史数据只可作为 pytest fixture；
- Artifact 只读取服务端登记对象；listener 始终保留 `index_id + frame_id` 复合键
  和详情深链；wait 有客户端 deadline 和合理 interval，单次服务端 wait 不超过
  30 秒，终态即停止；
- P3-P8 进入前逐阶段取得人工确认。任何旧目录删除、移动、merge 或远端历史改写

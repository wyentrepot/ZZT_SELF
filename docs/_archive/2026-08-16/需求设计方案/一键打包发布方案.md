# 一键打包发布方案

> **文档用途**：将现有打包流程改造为"一键打包到发布文件夹"的端到端方案，使打包产物可在其他电脑直接使用。
>
> **创建时间**：2026-08-06
> **状态**：方案已确认，待实施
> **决策**：发布目录取代 `dist/`，脚本 `一键打包-发布.bat` 放仓库根目录

---

## 一、背景与目标

### 1.1 现状

当前打包流程依赖 `packaging/build_exe.bat`，通过 PyInstaller onedir 模式将 Python Web 服务 + C# DLL 打包为免安装 Windows 可执行程序，产物输出到 `dist/侦听台/`（约 43MB，含 134 个 Git LFS 跟踪文件）。

**存在问题**：

- 打包脚本 `build_exe.bat` 藏在 `packaging/` 子目录下，不易发现；
- 输出目录 `dist/` 是 PyInstaller 默认路径，语义不够明确；
- 没有打包后自动验证的步骤（需手动跑冒烟测试）。

### 1.2 目标

- 新建根目录 `一键打包-发布.bat`，双击即可完成全流程；
- 产物输出到 `发布/侦听台/` 目录，**取代现有 `dist/`**；
- 打包后自动执行冒烟测试，确保产物可用；
- 发布目录的产物拷贝到其他 Windows 10/11 电脑即可直接运行，无需安装 Python 或任何依赖。

---

## 二、可行性分析

### 2.1 技术可行性：✅ 完全可行

核心依据：**frozen 路径解析不依赖目录名**。

`hplc_web/app.py` 中的路径解析逻辑：

```python
# app.py:32-36 — 运行时数据目录
def _runtime_dir() -> Path:
    if _is_frozen():
        return Path(sys.executable).resolve().parent / "runtime"
    return _base_dir() / "runtime"

# app.py:39-43 — DLL 默认路径
def _default_dll() -> Path:
    if _is_frozen():
        return _base_dir() / "dll" / "bin" / "Debug" / "GwHPLCAnalysis.dll"
    return (_base_dir().parent / "dll" / "bin" / "Debug" / "GwHPLCAnalysis.dll").resolve()
```

- `_runtime_dir()` 用 `sys.executable`（exe 自身路径）定位，与目录名无关；
- `_default_dll()` 用 `sys._MEIPASS`（PyInstaller 解包目录）定位，与目录名无关；
- **无论 exe 放在 `dist/` 还是 `发布/` 还是任意文件夹，路径均能正确解析。**

### 2.2 PyInstaller `--distpath` 参数

PyInstaller 原生支持 `--distpath` 命令行参数指定输出目录：

```bash
python -m PyInstaller --clean --noconfirm --distpath 发布 packaging\hplc_parser.spec
```

产物直接输出到 `发布/侦听台/`，`dist/` 不再产生文件。无需修改 spec 文件中的 `COLLECT` 逻辑。

### 2.3 目标机兼容性

| 条件 | 要求 | 现状 |
|------|------|------|
| 操作系统 | Windows 10/11 | ✅ 已验证 |
| .NET Framework | 4.8（Win10 1903+ 自带） | ✅ VCRUNTIME140.dll 已打包 |
| Python | 不需要 | ✅ onedir 自带 python313.dll |
| 额外依赖 | 无 | ✅ 所有依赖 DLL 均在 `_internal/` |

### 2.4 风险评估

| 风险 | 等级 | 说明 | 应对 |
|------|------|------|------|
| 旧 `dist/` 目录残留 | 中 | 需从 git 中移除并清理 LFS 指针 | `git rm -r dist/` 后提交 |
| LFS 历史膨胀 | 低 | dist 的 LFS 对象仍在历史中 | 可后续用 `git lfs migrate` 清理，不影响当前使用 |
| 中文路径 `发布` 兼容性 | 低 | `xcopy`/PyInstaller 在 Windows 上 GBK 中文路径正常 | 已验证 cmd 默认 codepage 支持 |
| 杀毒软件误报 | 低 | PyInstaller onedir exe 通用问题 | 非本次改动引入，可加数字签名后续解决 |
| `--distpath` 与 spec 交互 | 低 | PyInstaller 6.21.0 `--distpath` 对 spec 模式行为正常 | 实施时冒烟测试验证 |

## 四、实现细节

### 4.1 `一键打包-发布.bat`

```batch
@echo off
setlocal
cd /d "%~dp0"
title 一键打包到发布文件夹
set "RELEASE_DIR=发布"
set "APP_NAME=侦听台"

echo.
echo  ============================================
echo    侦听台一键打包
echo    输出目录: %RELEASE_DIR%\%APP_NAME%\
echo  ============================================
echo.

REM --- 前置检查 ---
if not exist ".venv\Scripts\python.exe" (
    echo [ERROR] .venv not found.
    echo 请先运行一次「启动解析工具.bat」以创建 Python 虚拟环境。
    pause & exit /b 1
)
if not exist "dll\bin\Debug\GwHPLCAnalysis.dll" (
    echo [ERROR] dll\bin\Debug\GwHPLCAnalysis.dll not found.
    echo 请先用 Visual Studio 生成 C# 工程 DLL_NwHPLCAnalysis。
    pause & exit /b 1
)

REM --- Step 1: 安装 PyInstaller ---
echo [1/4] 安装 PyInstaller...
".venv\Scripts\python.exe" -m pip install pyinstaller
if errorlevel 1 goto :failed

REM --- Step 2: PyInstaller 打包到 发布/ ---
echo [2/4] 构建 onedir 包...
".venv\Scripts\python.exe" -m PyInstaller --clean --noconfirm --distpath "%RELEASE_DIR%" packaging\hplc_parser.spec
if errorlevel 1 goto :failed

REM --- Step 3: 清理旧的 runtime 数据（如有） ---
if exist "%RELEASE_DIR%\%APP_NAME%\runtime" rmdir /s /q "%RELEASE_DIR%\%APP_NAME%\runtime"

REM --- Step 4: 冒烟测试 ---
echo [3/4] 冒烟测试...
".venv\Scripts\python.exe" scripts\smoke_test_packaged.py "%RELEASE_DIR%\%APP_NAME%\%APP_NAME%.exe"
if errorlevel 1 goto :failed

echo.
echo  [4/4] 完成！
echo.
echo  ============================================
echo    [成功] 打包完成！
echo    发布目录: %CD%\%RELEASE_DIR%\%APP_NAME%\
echo.
echo    使用方法：将整个「%APP_NAME%」文件夹拷贝到
echo    其他 Windows 10/11 电脑，双击 %APP_NAME%.exe 即可。
echo  ============================================
echo.
pause
exit /b 0

:failed
echo.
echo  [ERROR] 打包失败，请查看上方错误信息。
pause
exit /b 1
```

### 4.2 `.gitattributes` 改动

**删除**旧规则：

```gitattributes
# 旧规则（删除）
dist/**/*.exe filter=lfs diff=lfs merge=lfs -text
dist/**/*.dll filter=lfs diff=lfs merge=lfs -text
dist/**/*.pyd filter=lfs diff=lfs merge=lfs -text
dist/**/*.dylib filter=lfs diff=lfs merge=lfs -text
```

**替换**为新规则：

```gitattributes
# 发布目录：Git LFS 跟踪打包产物（onedir 分发包，避免大文件直接入库）
发布/**/*.exe filter=lfs diff=lfs merge=lfs -text
发布/**/*.dll filter=lfs diff=lfs merge=lfs -text
发布/**/*.pyd filter=lfs diff=lfs merge=lfs -text
发布/**/*.dylib filter=lfs diff=lfs merge=lfs -text
```

### 4.3 `.gitignore` 改动

**删除**旧规则：

```gitignore
# 旧规则（删除）
# PyInstaller 中间产物
build/
# 每个 onedir 分发包根目录下的 runtime/（冒烟生成的索引），不入库
dist/*/runtime/
# 豁免：pythonnet 自带的 .NET 运行时目录
!dist/*/_internal/pythonnet/runtime/
!dist/*/_internal/clr_loader/ffi/dlls/x86/
!dist/*/_internal/dll/bin/
!dist/*/_internal/dll/bin/Debug/
```

**替换**为新规则：

```gitignore
# PyInstaller 中间产物
build/
dist/

# 发布目录：每个 onedir 分发包根目录下的 runtime/（冒烟生成的索引），不入库
# 注意不能用 发布/**/runtime/：会误伤 _internal/pythonnet/runtime/
发布/*/runtime/
# 豁免：pythonnet 自带的 .NET 运行时目录
!发布/*/_internal/pythonnet/runtime/
!发布/*/_internal/clr_loader/ffi/dlls/x86/
!发布/*/_internal/dll/bin/
!发布/*/_internal/dll/bin/Debug/
```

### 4.4 `scripts/smoke_test_packaged.py` 改动

```python
# 修改前
```

```python
"""

在仓库根目录运行：
    .venv\Scripts\python.exe -m PyInstaller --clean --noconfirm --distpath 发布 packaging\hplc_parser.spec
"""
```

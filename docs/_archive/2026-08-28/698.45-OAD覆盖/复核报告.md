# adapter_698 oad.json 协议语义复核报告

- 复核文件：`libs/parser_lib/adapters/adapter_698/metadata/oad.json`（当前 52 条）
- 协议基准：DL/T 698.45—201X《电能信息采集与管理系统 面向对象的数据交换协议》附录A（对象标识定义）
- 复核方式：只读复核；本报告只读不改任何源文件
- 复核日期：2026-08-28

---

## 1. 复核结论（摘要）

| 项目 | 结果 |
| --- | --- |
| 总条目数 | 52 |
| OI↔名称 一致 | 16 条 |
| OI↔名称 不一致 | 36 条 |
| key 规范（8位大写hex、无重复） | 全部通过 |
| 总体结论 | **需修正** |

核心问题集中在三处：

1. **3000/3001 系列错位（7条）**：OAD 中 3000 系列被命名为"电能"，但协议附录A中 **3000=电能表失压事件、3001=电能表欠压事件**（事件类），电能量类 OI 实际为 0000~0503。该组 7 条全部为 OI↔名称错位。
2. **2002/2003 系列错位（9条）**：协议中 **2002=电压相角、2003=电压电流相角**，而 OAD 将其命名为"频率"（应为 200F 电网频率）和"瞬时有功/无功/视在功率"（应分别为 2004/2005/2006）。
3. **事件/冻结/通信类对象 OI 张冠李戴（20条）**：6000/6001/6002 在协议中为采集监控类（采集档案配置表/采集档案配置单元/搜表），F100 为 ESAM，2000+0x20~22 为电压对象的非标准属性，均被误标为事件/冻结对象。

---

## 2. 复核方法

- 对每条 8 位 key 按 `OI(4位) + 属性(2位) + 索引(2位)` 拆解；
- 将前 4 位 OI 与协议附录A 表 A.1~A.14（电能量类/最大需量类/变量类/事件类/参变量类/冻结类/采集监控类/集合类/控制类/文件传输类/ESAM接口类/输入输出设备类/显示类）逐项比对对象名称；
- 对 data_type、unit、scale 对照附录中对象定义的数据类型、单位与换算。

## 5. 结论

**需修正。**

- 52 条中仅 16 条（约31%）OI↔名称与协议附录A一致；
- 36 条 OI↔名称不一致，其中 **3000/3001 系列（P01/P02）为最高优先级**——事件 OI 被当作电能读取，真机解析必然错位；
- 2002/2003/2004 系列（P03/P04/P05）同属"相邻 OI 借位"型错误，建议整体核对变量类 OI 排布；
- 6000/6001/6002、F100、2000+0x20~22（P06/P07/P08）为对象类归属张冠李戴；
- 4001 系列（P09）与 0015（P10）为协议外/设备自定义 OAD，若确为厂商扩展，应在 desc 中显式标注"自定义OAD"，否则按协议修正。

建议修正方式：以协议附录A 为准重新编排 OI 映射；对于确为设备/固件自定义的 OAD（如 IMA 参考固件样例），保留 key 但需在 desc 标注"自定义"并附固件出处，避免与国标对象混淆。

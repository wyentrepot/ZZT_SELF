## 4. 架构要点（摘自 docs/05 方案）

- 覆盖入口：listener / module_log（cco+sta）/ flash_module / sim_concentrator / workbench 复制页面。
- 保留 local 模式；旧请求未传 transport 默认 local。
- 同一 COM 严格独占；不共享、不抢占、不排队。二次申请返回 409 PORT_IN_USE + owner。
- TCP 中断/串口拔出 = 操作失败、关闭串口、释放租约；不自动重连、不续跑。
- 普通数据在 Windows 不解析、不修改、不补 CR/LF；TCP 分包不是帧边界。
- XMODEM 是唯一业务例外：共享路径只读固件，先校验 size/SHA-256；Windows 本地动态波特率/ACK/NAK/重试；恢复波特率失败 → FLASH_RESTORE_FAILED 且 session 关闭。
- 同机限制：只绑定 127.0.0.1 + WSL 虚拟接口；HTTP Bearer token；TCP 握手校验 token/instance_id/session_id。
- bridge.json 原子写入 `D:\019-wy-tool\uart_to_tcp\runtime\bridge.json`，WSL 从 `/mnt/d/019-wy-tool/uart_to_tcp/runtime/bridge.json` 读；正常退出删除。
- 默认控制端口 32100、数据端口 32101，以 bridge.json 为事实来源。
- 七态状态机：created → awaiting_data → open → flashing → open → closing → closed；活动态 → error → closed；不从 error 自动恢复。
- owner 固定：listener、module_log:cco、module_log:sta、module_log:flash、sim_concentrator。
- 推荐 Python 3.11、Tkinter、pyserial、FastAPI/uvicorn、PyInstaller（onedir 优先）。

## 6. Control API v1 一览

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /v1/health | 实例健康 |
| GET | /v1/ports | COM、描述、busy、owner |
| POST | /v1/sessions | 校验参数、打开并租用 COM |
| GET | /v1/sessions/{id} | 状态、参数、计数 |
| PATCH | /v1/sessions/{id}/config | 修改允许的串口参数 |
| DELETE | /v1/sessions/{id} | 幂等关闭和释放 |
| POST | /v1/sessions/{id}/flash | 启动 XMODEM |
| GET | /v1/sessions/{id}/flash | 查询进度和终态 |

错误码：BRIDGE_UNAVAILABLE、AUTH_FAILED、INVALID_REQUEST、PORT_NOT_FOUND、PORT_IN_USE、PORT_OPEN_FAILED、SERIAL_READ_FAILED、SERIAL_WRITE_FAILED、SERIAL_CONFIG_FAILED、DATA_HANDSHAKE_TIMEOUT、TCP_DISCONNECTED、SESSION_NOT_FOUND、SESSION_FLASHING、FIRMWARE_NOT_FOUND、FIRMWARE_UNREADABLE、FIRMWARE_SIZE_MISMATCH、FIRMWARE_HASH_MISMATCH、FLASH_FAILED、FLASH_RESTORE_FAILED。

### 阶段 2：COM 会话、Control API 与 TCP 转发
- serial_session.py + session_manager.py：七态状态机、严格独占、异常释放、阻塞 read 不在管理锁内。

### 阶段 3：Windows XMODEM 服务
- xmodem_service.py：移植 apps/module_log/xmodem_flash.py（CRC16 0x31C3、128/1K 包、bootloader 导航、ACK/NAK/超时、动态波特率、恢复）。
- 烧录前校验 session/owner/文件只读/size/SHA-256/slot/baud_plan；失败零写入。
- 唯一 read 循环投递响应队列；flashing 拒绝普通写/配置；恢复失败 → FLASH_RESTORE_FAILED 且关闭。
- POST/GET /v1/sessions/{id}/flash，进度 state/phase/packet/total/baudrate/message/error。

### 阶段 4：WSL 共享后端 + 四类应用接入

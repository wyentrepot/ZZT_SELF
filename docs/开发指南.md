# ZZT_SELF 开发指南

> 项目：侦听台改造（HPLC 抄表通信报文侦听、解析与分析工具）
> 配套文档：`docs/WSL 开发环境使用手册.md`（环境与串口）、`README.md`（项目结构）、`doc/一键打包发布方案.md`（打包）
> 本指南定位：**开发主战场在 WSL，硬件/桌面/打包在 Windows，告诉你怎么干活。**

---

## 0. 环境认知（先读这段，避免踩坑）

**核心事实：Windows 工作区受 E-SafeNet 透明加密影响，所有 `.py` 在磁盘上是密文，任何非白名单进程（命令行 python、IDE 子进程、PyInstaller）读到的都是密文，跑源码会报 `SyntaxError: source code string cannot contain null bytes`。**

因此：

| 环境 | 用途 | 能不能直跑源码 |
|---|---|---|
| **WSL**（`/01-workfile-ai/01-zzt/ZZT_SELF`） | 开发、测试、Web 服务 | ✅ 明文，随便跑 |
| **Windows**（`D:\019-wy-tool\ZZT_SELF`） | 硬件串口、桌面 exe、打包 | ❌ 源码是密文，别直跑 |

> **规则一**：写代码 / 改逻辑 / 跑测试，一律去 WSL。
> **规则二**：WSL 不要读 `/mnt/d` 上的项目源码（那是密文），只用自己的 ext4 副本。
> **规则三**：Windows 侧源码直跑（`python -m module_log.desktop` 等）在当前环境行不通，改用构建好的 exe 或去 WSL。

## 1. 两个应用

| 应用 | 目录 | 端口 | 干什么 |
|---|---|---|---|
| **侦听台** | `listener/` | 8765 | 串口采集 + HPLC 报文解析 + 日志索引/分钟分析 |
| **模块日志/烧录** | `module_log/` | 8766 | 模块串口实时日志 + XMODEM 固件烧录 |

两者独立运行、互不依赖，共享 `shared/` 基础设施。

### 关键模块速查

```
listener/         侦听台
  app.py            FastAPI 应用
  run.py            启动入口（python -m listener.run）
  serial_service.py 串口采集（需真实 COM）
  desktop.py        pywebview 桌面窗口（仅 Windows 用）
module_log/       模块日志/烧录
  app.py            FastAPI 应用
  run.py            启动入口（python -m module_log.run）
  desktop.py        pywebview 桌面窗口（仅 Windows 用）
  module_serial_service.py  串口服务（COM 读写）
  xmodem_flash.py           XMODEM 协议（纯逻辑）
  flash_module.py           独立烧录脚本
loghooks/         日志规则引擎（纯逻辑，可单测）
parser_lib/       报文解析路由（纯逻辑，可单测）
shared/           共享：infra / parser_service / application_service / dll
packaging/        打包脚本（build_exe.bat + *.spec + check_encrypted.py）
```

## 2. 日常开发流程（WSL）

```bash
# 进入工作区
cd /01-workfile-ai/01-zzt/ZZT_SELF

# 1. 拉取最新
git pull

# 2. 改代码（明文，VSCode WSL 远程 / vim 皆可）
#    code module_log/app.py

# 3. 跑测试（纯逻辑部分，秒过）
python3 -m pytest loghooks/ -q
python3 -m pytest module_log/test_loghooks_api.py -q

# 4. 起 Web 服务（module_log 为例）
python3 -m uvicorn module_log.app:app --host 0.0.0.0 --port 8766
#    Windows 浏览器访问 http://localhost:8766（WSL2 自动转发 localhost）
#    侦听台：python3 -m uvicorn listener.app:app --port 8765

# 5. 提交推送
git add -A
git commit -m "feat(module_log): 说明改动内容"
git push
```

### 提交信息规范（参照现有历史）
- `feat(x): ...` 新功能；`fix(x): ...` 修复；`docs(x): ...` 文档；`refactor(x): ...` 重构
- `x` 是模块名，如 `module_log` / `listener` / `loghooks` / `packaging` / `launcher`

## 4. 硬件串口（烧录 / 采集）

**串口已映射**（`.wslconfig`）：Windows COM3 → WSL `/dev/ttyS3`，COM23 → `/dev/ttyS23`。

```bash
# 验证串口
python3 -c "import serial; s=serial.Serial('/dev/ttyS3',115200,timeout=0.5); print('OK',s.name); s.close()"
```

- 需要真实硬件时，**在 WSL 用映射串口** 或 **Windows 侧用工具**。
- 同一串口同一时刻只能一端占用（WSL 占用时 Windows 侧打不开，反之亦然）。
- 若换机器 COM 号不同，改 `C:\Users\<user>\.wslconfig` 的 `[serialports]` 段，`wsl --shutdown` 后重启。

## 5. 桌面窗口 / 打包（Windows 侧）

| 需求 | 操作 |
|---|---|
| 启动桌面软件 | `启动工具.bat` 选 4（模块日志 exe）或选 5（侦听台 exe） |
| 打包 exe | `packaging\build_exe.bat`（已适配 E-SafeNet：检测密文→git 明文副本构建） |
| 产物 | `dist\模块日志\`、`dist\侦听台\`（不入 git） |

> 桌面 exe 只能在 Windows 打包（PyInstaller 打 Windows exe）。WSL 不负责打包。

## 6. 双环境 git 同步

- **WSL 与 Windows 是两份 git 副本**，都指向同一个远程：`git@github.com:wyentrepot/ZZT_SELF.git`。
- 日常：**在 WSL 开发 → commit → push → 到 Windows 侧 pull**（或反之）。
- 谁改了都要先 `git pull` 再改，避免冲突。
- WSL 里 push 需要 SSH key（`~/.ssh/id_ed25519`），没配就 `git config` 用 HTTPS + token。

## 7. 常见坑速查

| 症状 | 原因 | 处理 |
|---|---|---|
| `SyntaxError: source code string cannot contain null bytes` | 在 Windows 直跑密文源码 | 去 WSL 跑，或改用 exe |
| 打开串口报 `Input/output error` | 未映射 / 设备未插 / 未重启 WSL | 检查 `.wslconfig`，`wsl --shutdown` 后重开 |
| 打开串口报 `Access denied` | 该 COM 被另一端占用 | 先释放 Windows/WSL 侧占用 |
| `Hidden import 'uvicorn.xxx' not found` | venv 缺运行依赖 | `pip install -r module_log/requirements.txt`（build_exe.bat 已自动装） |
| 打包读源码报错 | E-SafeNet 密文 | 用 `build_exe.bat`（自动 git 明文副本），勿手动跑 PyInstaller |

## 8. 新机器初始化（备用）

```bash
# 1. 装 WSL + Ubuntu-22.04
wsl --install -d Ubuntu-22.04

# 2. WSL 里 clone + 装依赖
cd ~
git clone git@github.com:wyentrepot/ZZT_SELF.git
cd ZZT_SELF
pip install fastapi uvicorn httpx pyserial pytest pyinstaller pywebview

# 3. 串口映射（.wslconfig）
#    [serialports] 段按实际 COM 口配置，wsl --shutdown 后生效

# 4. 验证
python3 -m pytest loghooks/ -q
```

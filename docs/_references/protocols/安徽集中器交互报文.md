集中器与本地通信模块（CCO）之间的 AFN+FN 帧格式，属于分钟级采集扩展协议。以下基于安徽方案，列举所有涉及的应用层扩展帧格式。

---

# 安徽分钟级采集 Q/GDW 10376.2 应用层扩展帧（AFN+FN）

---

## 二、帧格式详解

### 1. AFN=03H, FN=F10 — 本地通信模块运行模式信息

**下行**：确认/否认帧，无数据单元。

**上行**：通信模式字（6字节BS），其中扩展分钟采集标志：


| 比特位            | 含义                                     |
| ----------------- | ---------------------------------------- |
| D5（第6字节bit5） | **是否支持分钟级采集**：0=不支持，1=支持 |

其余字段为：本地通信模式字、周期抄表模式、通信方式（HPLC/HRF双模）、广播命令执行方式、信道数量、速率数量、从节点监控超时等。

---

### 2. AFN=05H, FN=F10 — 设置双模串口速率

**下行**：


| 数据内容   | 格式 | 字节数 |
| ---------- | ---- | ------ |
| 通信速率值 | BIN  | 1      |

速率值定义：0=9600, 1=19200, 2=38400, 3=57600, **4=115200**

---

### 3. AFN=06H, FN=F3 — 上报路由工况变动信息

**上行**：


| 数据内容             | 格式 | 字节数 | 含义                                                                                                     |
| -------------------- | ---- | ------ | -------------------------------------------------------------------------------------------------------- |
| 路由工作任务变动类型 | BIN  | 1      | 1=抄表任务结束；2=搜表任务结束；3=台区识别任务结束；**4=分钟级主动上报空闲**（每个周期都上报）；其他保留 |

---

### 4. AFN=06H, FN=F230 — 采集任务数据上报

**下行**：确认/否认帧，无数据单元。

**上行**：


| 数据内容     | 格式                   | 字节数 | 说明               |
| ------------ | ---------------------- | ------ | ------------------ |
| 任务号       | BIN                    | 1      | 1\~15              |
| 从节点地址   | BCD                    | 6      | 电表MAC            |
| 通信协议类型 | BIN                    | 1      | 2=645, 3=698       |
| 采集时间     | BCD(YY-MM-DD-HH-MM-SS) | 6      |                    |
| 报文长度 L   | BIN                    | 2      | 后续报文内容字节数 |
| 报文内容     | —                     | L      | 645/698原始报文    |

---

### 5. AFN=10H, FN=F2 — 查询从节点信息

**下行**：无数据单元。

**上行**：


| 数据内容               | 格式 | 字节数 |
| ---------------------- | ---- | ------ |
| 从节点总数量           | BIN  | 2      |
| 本次应答的从节点数量 n | BIN  | 1      |
| 从节点1地址            | BCD  | 6      |
| 从节点1信息            | BS   | 2      |
| ...                    | ...  | ...    |
| 从节点n地址            | BCD  | 6      |
| 从节点n信息            | BS   | 2      |

**从节点信息字扩展**（高字节D15-D8）：


| D15  | D14                  | D13-D11      | D10-D8 |
| ---- | -------------------- | ------------ | ------ |
| 备用 | **是否支持分钟采集** | 通信协议类型 | 相位   |

D14=1表示支持分钟采集，D14=0表示不支持。

---

### 6. AFN=10H, FN=F4 — 路由运行状态查询

**下行**：无数据单元。

**上行**：路由运行状态字，其中含组网完成标志。

---

### 7. AFN=10H, FN=F230 — 采集任务数量查询

**下行**：无数据单元。

**上行**：


| 数据内容       | 格式 | 字节数 | 含义                                        |
| -------------- | ---- | ------ | ------------------------------------------- |
| 采集任务总数   | BIN  | 1      | 1\~15有效                                   |
| 采集任务号位图 | BIN  | 4      | 32位整数，bit0=任务0存在，bit1=任务1存在... |

---

### 8. AFN=10H, FN=F231 — 采集任务配置查询

**下行**：


| 数据内容   | 格式 | 字节数 | 含义         |
| ---------- | ---- | ------ | ------------ |
| 采集任务号 | BIN  | 1      | 1\~15有效    |
| 协议类型   | BIN  | 1      | 2=645, 3=698 |

**上行**：


| 数据内容       | 格式 | 字节数 | 含义                    |
| -------------- | ---- | ------ | ----------------------- |
| 任务号         | BIN  | 1      | 1\~15                   |
| 协议类型       | BIN  | 1      | 2=645, 3=698            |
| 采集周期       | BIN  | 1      | 单位：分钟              |
| 任务关联电表数 | BIN  | 2      |                         |
| 单相表(0x00)   | BIN  | 1      | 固定值                  |
| 数据项数量 n   | BIN  | 1      | 未配置则填0，无后续字段 |
| 数据项标识1\~n | BIN  | 4×n   | 各4字节                 |
| 三相表(0x01)   | BIN  | 1      | 固定值                  |
| 数据项数量 m   | BIN  | 1      |                         |
| 数据项标识1\~m | BIN  | 4×m   |                         |
| 其他表(0x02)   | BIN  | 1      | 固定值                  |
| 数据项数量 k   | BIN  | 1      |                         |
| 数据项标识1\~k | BIN  | 4×k   |                         |

---

### 9. AFN=10H, FN=F232 — 采集任务关联档案查询

**下行**：


| 数据内容             | 格式 | 字节数 | 含义    |
| -------------------- | ---- | ------ | ------- |
| 采集任务号           | BIN  | 1      | 1\~15   |
| 任务关联电表起始序号 | BIN  | 2      | 从1开始 |
| 查询数量             | BIN  | 1      |         |

**上行**：


| 数据内容           | 格式 | 字节数 | 含义 |
| ------------------ | ---- | ------ | ---- |
| 采集任务号         | BIN  | 1      |      |
| 任务关联电表总数   | BIN  | 2      |      |
| 本次应答电表总数 n | BIN  | 1      |      |
| 电表地址1\~n       | BCD  | 6×n   |      |

---

### 10. AFN=11H, FN=F231 — 采集任务配置（核心）

**下行**：


| 数据内容               | 格式 | 字节数 | 含义                                   |
| ---------------------- | ---- | ------ | -------------------------------------- |
| 任务号                 | BIN  | 1      | **1\~15有效**，0xFF=全部任务（仅删除） |
| 启用/删除标志          | BIN  | 1      | 0=删除，1=启用                         |
| 协议类型               | BIN  | 1      | 2=645，3=698                           |
| 采集周期               | BIN  | 1      | 单位：分钟                             |
| **单相表(0x00)**       | BIN  | 1      | 固定值                                 |
| 数据项数量 n           | BIN  | 1      | 删除时填0，无后续                      |
| 预计回复总长度 Ln      | BIN  | 2      | 该表类型所有数据项回复长度累加和       |
| 数据项标识1            | BIN  | 4      |                                        |
| 数据项标识1回复长度 L1 | BIN  | 1      | 数据项value长度                        |
| ...                    | ...  | ...    |                                        |
| **三相表(0x01)**       | BIN  | 1      | 固定值                                 |
| 数据项数量 m           | BIN  | 1      |                                        |
| 预计回复总长度 Lm      | BIN  | 2      |                                        |
| 数据项标识1\~m         | BIN  | 4×m   |                                        |
| 数据项标识1\~m回复长度 | BIN  | 1×m   |                                        |
| **其他表(0x02)**       | BIN  | 1      | 固定值（光伏表、导轨表）               |
| 数据项数量 k           | BIN  | 1      |                                        |
| 预计回复总长度 Lk      | BIN  | 2      |                                        |
| 数据项标识1\~k         | BIN  | 4×k   |                                        |
| 数据项标识1\~k回复长度 | BIN  | 1×k   |                                        |

**上行**（确认/否认）：


| 数据内容      | 格式 | 字节数 | 含义                                                                                           |
| ------------- | ---- | ------ | ---------------------------------------------------------------------------------------------- |
| 任务号        | BIN  | 1      |                                                                                                |
| 启用/删除标志 | BIN  | 1      |                                                                                                |
| 协议类型      | BIN  | 1      |                                                                                                |
| 采集周期      | BIN  | 1      |                                                                                                |
| 配置结果      | BIN  | 1      | 0=成功；1=失败任务号不存在；2=失败任务号重复；3=失败协议类型未知；4=失败任务数量越界；其他保留 |

**注**：安徽方案任务号范围1\~15，HDC手册为0\~7，重庆方案为0\~15。

---

### 11. AFN=11H, FN=F232 — 采集任务关联档案配置

**下行**：


| 数据内容   | 格式 | 字节数 | 含义      |
| ---------- | ---- | ------ | --------- |
| 任务号     | BIN  | 1      | 1\~15有效 |
| 档案个数 N | BIN  | 2      |           |
| 档案地址1  | BCD  | 6      | 电表地址  |
| 档案地址2  | BCD  | 6      |           |
| ...        | ...  | ...    |           |
| 档案地址N  | BCD  | 6      |           |

**上行**（确认/否认）：


| 数据内容 | 格式 | 字节数 | 含义                                           |
| -------- | ---- | ------ | ---------------------------------------------- |
| 任务号   | BIN  | 1      |                                                |
| 配置结果 | BIN  | 1      | 0=成功；1=失败存在未知任务；2=失败存在未知档案 |

## 四、编程关键点

1. **任务号范围**：安徽1\~15，重庆0\~15，HDC手册0\~7。安徽用0xFF表示全部任务（仅删除）
2. **配置结果码**：安徽4种（0成功/1任务号不存在/2任务号重复/3协议类型未知/4任务数量越界），重庆7种（多了5配置参数错误/6CCO正在组网）
3. **关联档案配置**：档案数量多时需分多次下发，每次档案数量N用2字节BIN
4. **数据上报AFN=06H-F230**：上行报文长度L用2字节BIN，下行用确认/否认帧
5. **分钟采集标志**：03H-F10的D5位和10H-F2的D14位是两个独立位置，前者表示CCO支持，后者表示STA支持
6. **工况变动AFN=06H-F3**：类型4（分钟级主动上报空闲）每个周期都上报

实现红线 · 五条

1 · 三列级联是骨架 — 主功能页（侦听台/模拟集中器/追踪/字典/场景）一律三列：清单列 → 明细列 → 详情列，宽度只许微调不许换布局。
2 · 协议数据必须等宽 — hex、OAD/DI 键、BCD 地址、报文序号、时间戳一律 --fm 等宽字体，禁止比例字体混排。
3 · 状态只用语义色 — 成功/警示/失败/不可判定只准用 --ok/--warn/--err；inconclusive 用琥珀，绝不复用绿或红。
4 · 空态要有引导 — 未选择时给级联路径提示（如“AFN 列 → Fn 列 → 字段参数”），禁止白板。
5 · 可折叠就要可展开 — 侧栏、底部记录、卡片组全部支持收展，动画 0.2s cubic-bezier(.4,0,.2,1)，尊重 prefers-reduced-motion。

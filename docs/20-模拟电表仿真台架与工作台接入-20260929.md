## 1. 结论摘要（TL;DR）

1. **vbench 虚拟串口台架落成**（`tools/vbench/`，独立子项目）：openpty 伪终端对 +
   模拟 CCO/STA 工作节奏，17 项台架测试全绿，覆盖 sim_meter 黑盒/白盒、
   sim_concentrator 黑盒/白盒、端到端节奏（抄表数据上报集中器，docs/19 的通过标准之软件仿真版）。
2. **子项目定位**（与需求方对齐）：仅用于日常开发/CI 平替实机；**不做** AI 工作台技能；
   **唯一数据交换通道是虚拟串口字节流**（角色间零 Python 耦合，HPLC 跳＝星型字节泵）。
3. **工作台接入 sim_meter**：`/api/simeter` 挂载（带资源注册表防双开 + mapping_id 解析）、
   AI v2 只读观察能力 `simeter_frames.read`（含 call_examples 小抄）、`GET /api/simeter/_meta`
   自描述端点、专页 UI（`#simeter`：状态/配置/帧流/645 调测台）。
4. **台架测试发现并修复 2 个 sim_meter 真实缺陷**：`tx_count` 恒 0；脏流/698 假头令切帧器
   卡死（电表"失聪"）——实机台必踩，已修。
5. 修复 3 处既有测试债：clock 正则、2 个依赖仓库实况串口目录的 API 测试（改为自建隔离目录态）。
   另有 7 个**既有**失败（profile_loading×2、store_query×5）经 git stash 基线确认为本次改动前已存在，待单独清理。

## 2. 环境与协议口径（台架沉淀，详见 tools/vbench/README.md）

| 口径 | 结论 |
|---|---|
| WSL pts 与 PARENB | 6.18.33.2-microsoft-standard-WSL2 内核拒绝 pts 设置 PARENB（parity=E 打开即 EINVAL）；虚拟串口/桥接环境开口一律 parity=N，线参由对端（Windows 侧 CP210x）决定 |
| 645 CS | 从第一个 68 起至 CS 前（含两个 68）模 256；实机帧 `6899..996813007916` 吻合 |
| 13H 应答数据域 | 表地址原文（不加 33H）；91H 等读应答数据域 +33H |
| 1376.2 Fn 命名 | "14H-F2"＝Fn **2**（F 前缀+十进制显示），帧内 DT 线序 `02 00`；`_norm_fn("F2")==2` |
| pty 方向性 | 写主端→从端可读；角色都在主端收发，桥接泵必须走**从端** fd |
| bpsCheck 应答 | simcon 侧 local+echo（空 buff）即可让 CCO 判 local_rx_ok，与实机一致 |

## 3. vbench 台架（tools/vbench/）

- 拓扑：`simcon SerialIO ─ local_pair ─ FakeCCO ─(link_star 星型字节泵＝HPLC 共享媒介)─ FakeSTA×N ─ meter_pair×N ─ sim_meter×N`；
  CCO 下行所有 STA 都能听到，任一 STA 上行汇聚回 CCO（共享媒介语义）。
- FakeSTA 节奏：99×6/AA×6 广播 13H 逐轮扫掠 → 93H 命中 → 单表校验 → 读 DI 00010000 判定绑定
  （对照 H_STA aps_mclt_state.c 实机日志，docs/19 §3.2/3.3）。
- FakeCCO 节奏：14H-F2 时钟询问（bpsCheck）→ 10H-F2 档案应答 → 11H-F1 确认 → 13H-F1 路由抄读中继。
- 用法：`python3 -m tools.vbench bind|e2e|blackbox`；测试：`python3 -m pytest tools/vbench/tests/ -q`。

## 4. 工作台接入（AI 稳定调用）

- **API**：`/api/simeter/*`（open 支持 `mapping_id=listener`，经共享资源注册表防双开；
  close 释放注册）。挂载点 `apps/workbench/app.py` §2.6（`simeter_factory` 可注入供测试隔离）。
- **AI v2 能力**：`simeter_frames.read`（scope `simeter:read`，只读观察；investigations 可
  `{"source":"simeter"}` 采帧）。能力快照自带 call_examples；**写操作不经 AI 平面**，
  由小抄引导直连 HTTP。
- **自描述小抄**：`GET /api/simeter/_meta` —— 端点清单 + open_sequence + 错误语义 + 关键注记
  （默认地址 999999999999、三种广播、WSL parity=N 口径），AI 一次调用即可获得全部调用知识。
- **专页 UI**：壳导航「设备 → 模拟电表」（`#simeter`）：状态卡、配置卡（地址/版本/数据标识）、
  645 调测台（handle_hex 无串口可用）、会话帧流（自动刷新/方向过滤）。

## 5. 台架测试发现的缺陷与修复

| 缺陷 | 位置 | 修复 |
|---|---|---|
| `tx_count` 只定义从不自增（状态 API 恒 0） | `sim_meter/meter.py` | handle_frame 产出应答时自增 |
| 脏字节/假头（实机 STA 交替下发的 698 帧，L 字节 0xAA）令 DLT645 切帧器永久等待，电表"失聪" | `sim_meter/serial_channel.py` | 通道层重同步：buf[0]≠0x68 跳下一个 68；假头超 0.5s 跳 buf 内下一个 68 |

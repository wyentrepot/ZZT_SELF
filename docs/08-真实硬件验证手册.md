
## 4. COM23 XMODEM 烧录（写固件，不可完全回退）

```bash
# 1) dry-run 校验
python3 apps/module_log/flash_module.py --port /dev/ttyUSB2 \
    --bin /home/H_CCO/001/cco/firmware/iap_cco_AN_HUI_*.bin \
    --slot 0 --dry-run

# 2) 确认无误后真正烧录
python3 apps/module_log/flash_module.py --port /dev/ttyUSB2 \
    --bin /home/H_CCO/001/cco/firmware/iap_cco_AN_HUI_*.bin \
    --slot 0
```

**成功标志**：日志出现 `Image download OK` → `BURN SUCCESS`；模块 reboot。

> 注意：烧录前先 `--list-ports` 确认设备名；若 COM23 当前被其他程序占用，先关闭。
> 若固件在 Windows 侧使用 module_log 前端烧录，则先"恢复串口到 Windows"再操作（`串口映射.bat` 选 `[2]`）。

## 5. COM24 交互验证（anhui_minute_collect）

```bash
cd /01-workfile-ai/01-zzt/ZZT_SELF
python3 -m sim_concentrator verify \
    apps/workbench/scenarios/tasks/anhui_minute_collect.json \
    --port /dev/ttyUSB0 --baud 9600 --json
```

**期望**（9 步全部 PASS）：

| # | 步骤 | 说明 |
|---|---|---|
| 1 | 查询路由运行状态 10H-F4 | send+expect |
| 2 | 查询从节点信息 10H-F2 | send+expect |
| 3 | 查询采集任务数量 10H-F230 | send+expect |
| 4 | 查询任务配置 10H-F231 (任务7/645) | send+expect |

| 6 | 关联档案到任务 11H-F232 | send+expect |

- 步骤 5 的 11H-F231 下行 `buff="07 01 02 05 00 01 04 00 02 ..."` 中 **Ln=2 字节（04 00）**——若 CCO 回否认（配置结果≠0），检查 Ln 字节数与 CCO parse 差异
- 步骤 7~9 依赖 CCO 按周期主动上报；若全部超时，检查任务是否配置成功（步骤 5 结果）

## 一、项目简介

侦听台是一款面向**电力线载波（HPLC，High-speed Power Line Communication）** 抄表场景的通信报文侦听与分析工具。它可以捕获智能电表与集中器之间的 HPLC 通信帧，依据**国网 / 南网**两套协议规范对原始报文进行结构化解析，并提供分钟级报表分析、并发抄表分析、报文文件筛选等能力，帮助研发与运维人员排查通信问题、核对抄表数据。

项目采用 **C# 解析引擎 + Python Web 服务**的混合架构：核心解析逻辑由 C# 动态库（`GwHPLCAnalysis.dll`）实现，通过 `pythonnet` 在 Python 中调用；Web 服务基于 FastAPI 提供 REST API 与可视化界面，支持大文件流式索引与按需深度解析。

## 二、主要功能

| 功能 | 说明 |
|------|------|
| **HPLC 报文侦听与解析** | 按国网、南网协议解析原始通信报文，支持外层帧、FCH、MPDU 等完整链路 |
| **串口实时采集** | 从 COM19（115200/N/8/1）裸 7E 帧流实时读取 HPLC 帧，自动加时间戳，先落盘项目根 `LOG/` 文件夹，再实时入库，前端实时浏览 |
| **数据源二选一** | 串口实时监听与日志文件分析运行时互斥，切换即清空重建索引，避免数据混在一起 |
| **报文解析工具** | 对抓取的报文文件做结构化解析，逐帧展示摘要与详情 |
| **大文件流式索引** | 支持数百 MB 日志文件按行流式读取，SQLite 建立索引，不一次性加载到内存 |
| **分页浏览** | 帧列表分页展示（每页 ≤500 条），支持序号、时间字段筛选 |
| **单帧深度解析** | 点击帧后触发完整 DLL 解析，展示外层、MAC、FCH、MPDU 全链路 |
| **应用层富化** | 解析分钟采集数据、并发抄表帧，递归解出内嵌 DLT645 / DLT698.45 帧 |
| **分钟报表分析** | 对分钟级上报数据做状态统计与分析（`/api/logs/minute-analysis`） |
| **报文文件筛选** | 通过原生 Windows 文件对话框选择日志文件（`/api/fs/pick`） |
| **一键启动** | 生产模式与测试模式分离，启动器自动管理依赖与生命周期 |

## 三、技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| **解析引擎** | C# / .NET Framework 4.8 | 动态库 `GwHPLCAnalysis.dll`（工程 `dll/DLL_NwHPLCAnalysis`） |
| **Web 服务** | Python 3 + FastAPI + Uvicorn | `hplc_web/`，默认监听 `127.0.0.1:8765` |
| **C#/Python 互操作** | pythonnet（`clr`） | Python 中加载并调用 C# 动态库 |
| **解析库** | Python 3 | `parser_lib/`，纯 Python 实现协议适配器与核心框架 |
| **前端** | 原生 HTML + CSS + JavaScript | 单页应用，无需额外前端框架 |
| **数据库** | SQLite | 帧索引存储，支持大文件分页查询 |
| **依赖管理** | NuGet / pip | `Newtonsoft.Json` 等；`hplc_web/requirements.txt` |
| **打包部署** | PyInstaller | 打包为免安装 Windows 可执行程序（onedir） |

### 模块职责

| 模块 | 路径 | 职责 |
|------|------|------|
| **C# 解析 DLL** | `dll/` | 原始报文解析核心，实现国网/南网协议帧结构解析，输出结构化结果 |
| **Web 服务** | `hplc_web/` | FastAPI 应用，提供 REST API，通过 pythonnet 调用 C# DLL，前端 SPA 交互 |
| **Python 解析库** | `parser_lib/` | 纯 Python 协议适配器，实现 DLT645/698.45/10376/双模协议解析，补充 C# DLL 未覆盖场景 |
| **启动器** | 根目录 `.bat` | 自动创建 venv、安装依赖、管理服务生命周期 |

## 五、协议支持

| 协议 | 标准 | 说明 | 解析方式 |
|------|------|------|----------|
| **国网 HPLC 侦听台帧** | Q/GDW 11612 系列 | 国网双模通信互联互通技术规范，外层帧 `FF 02` 类型 | C# DLL + Python 富化 |
| **南网 HPLC 帧** | 南网低压电力线宽带载波通信规约 | 南方电网宽带载波通信协议 | C# DLL |
| **DL/T 645** | 多功能电能表通信协议 | 电表数据单元内嵌协议 | Python 适配器（`parser_lib/adapters/adapter_645/`） |
| **DL/T 698.45** | 电能信息采集与管理系统协议 | 面向对象的数据交换协议，用于并发抄表数据单元 | Python 适配器（`parser_lib/adapters/adapter_698/`） |
| **Q/GDW 10376.2** | 用电信息采集系统通信协议 | 集中器与采集终端之间的通信协议 | Python 适配器（`parser_lib/adapters/adapter_10376/`） |
| **双模 4-3 协议** | HPLC + RF 双模通信 | 分钟采集与并发抄表解析 | Python 适配器（`parser_lib/adapters/adapter_dualmode/`） |

## 九、一键使用（打包版）

仓库 `dist/侦听台/` 是免安装打包产物（onedir，Git LFS 跟踪）：

1. **克隆仓库**（需 Git for Windows 或单独安装 git-lfs，首次 clone 自动拉取 LFS 对象）；
2. **双击 `dist/侦听台/侦听台.exe`**；
3. **浏览器自动打开** `http://127.0.0.1:8765/`，即可选择日志建立索引、查看帧详情与分钟分析；
4. **关闭 exe 所在控制台窗口**即停止服务；索引数据库等运行时数据写入 exe 同目录 `runtime/`，不会污染仓库。

> **目标机要求**：Windows 10/11（自带 .NET Framework 4.8），无需安装 Python。

## 十、构建与运行

### 10.1 构建解析动态库

用 Visual Studio 打开 `DLL.sln`（或 `NwHplcDll.sln`）生成工程，产物为 `dll\bin\Debug\GwHPLCAnalysis.dll`。

### 10.2 启动服务

| 模式 | 命令 | 说明 |
|------|------|------|
| **生产模式** | `启动解析工具.bat` | 由用户选择日志文件 |
| **测试模式** | `启动解析工具-测试模式.bat` | 自动加载 `hplc_web/tests/data/gw_log_sample.txt`（约 234 KB，300 行） |

### 10.3 首次运行

启动器会自动创建 Python 虚拟环境 `.venv` 并安装 `hplc_web/requirements.txt` 中的依赖，随后打开浏览器访问 `http://127.0.0.1:8765/`。

### 10.4 停止服务

关闭启动器窗口即可停止本地服务。

### 10.5 重新打包 exe

运行 `packaging\build_exe.bat`（需先按 10.1-10.2 准备 venv 与 DLL），产物输出到 `dist\侦听台\`。

> 启动器会检测本地服务版本，若接口版本过旧会自动重启服务，无需手动干预。

## 十一、API 概览

Web 服务默认监听 `127.0.0.1:8765`，主要接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/version` | GET | 获取服务版本、DLL 名称与版本、API revision |
| `/api/parse` | POST | 解析单帧报文 |
| `/api/fs/pick` | POST | 原生 Windows 文件选择对话框 |
| `/api/fs/last` | GET | 上次打开的文件路径 |
| `/api/fs/roots` | GET | Windows 盘符列表 |
| `/api/logs/open` | POST | 开始建立日志索引 |
| `/api/logs/status` | GET | 索引进度 |
| `/api/logs/frames` | GET | 分页读取帧摘要 |
| `/api/logs/frames/{id}` | GET | 获取选中帧的完整解析 |
| `/api/logs/minute-analysis` | POST | 分钟报表数据分析 |
<| `/api/serial/ports` | GET | 列出可用串口 |
| `/api/serial/status` | GET | 串口采集状态（frame_count/log_dir/log_file） |
| `/api/serial/start` | POST | 启动串口采集（默认 COM19/115200/N/8/1） |
| `/api/serial/stop` | POST | 停止串口采集 |
| `/openapi.json` | GET | OpenAPI 完整接口描述 |

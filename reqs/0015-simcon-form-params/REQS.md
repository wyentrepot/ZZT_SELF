# REQS-0015 — simcon 参数区表单化（字段输入框 + 无数据单元隐藏 + UI 美化）

> 状态：🚧 进行中
> 创建：2026-09-01
> 关联：REQS-0013（1376.2 协议帧页面化重构）、REQS-0010（工作台 UI）

## 1. 背景与问题

REQS-0013 之后，simcon 页面（`apps/workbench/static/pages/simcon/`）的「参数与下发」栏仍沿用
旧形态：**JSON 大文本框（业务参数）+ 字段参考表格（字段/语义|格式|字节）**。用户 2026-09-01 反馈：

1. **无数据单元的 Fn**（初始化、路由控制重启/暂停/恢复等）——仍显示一栏 JSON 文本框，但实际"该命令无数据单元，直接下发即可"，应**隐藏业务参数栏**。
2. **有明确格式/单位的字段**（如 `持续时间 [BIN 1B] min`）——不应再用"参考表格 + JSON 文本框"，应**直接渲染成带单位的输入框**：`持续时间 [___] min`。
3. UI 需美观（对齐 tokens-v2 主题风格）。

## 2. 目标

1. 无数据单元 Fn → 不显示业务参数栏，仅提示「该命令无数据单元，直接下发即可」。
2. 有字段 Fn → 字段表单化：按字段的格式/单位/控件类型渲染输入控件（数字+单位、下拉、地址、时间、hex 报文、地址列表等），替换 JSON 文本框与字段参考表格。
3. 表单字段经业务键名（`key`）组装成下发参数，保持「send 只写业务参数、构帧自动完成」（ADR-5）语义不变。
4. 帧预览卡片保留（只算不发）。

## 3. 设计

### 3.1 字段业务键名（库驱动）

在 `afn_fn.json` 的 `req.fields[i]` 增加 `key` 字段（业务键名，对齐 `adapter_10376` 构帧模板）：
- 普通标量 → `"duration"` / `"timeout"` / `"start"` / `"count"` 等
- 自动计算字段（长度/数量）→ `key: null`，前端跳过不显示
- 特殊：`_time`=日期时间(BCD 6B)；`nodes`/`meters`/`relays`/`subs`=地址列表；`payload`/`data`/`content`=hex 报文

> 已通过 `scripts/migrate_afn_fn_v2.py` 的 `FIELD_KEYS`（34 项）注入。

### 3.2 前端表单渲染（simcon.js `selectFn` 重写）

| 字段特征 | 渲染控件 |
| --- | --- |
| `key == null` | 跳过（自动计算） |
| `c == "num"` 且有 `o`(单位) | 数字输入框 + 单位后缀（如 `[___] min`） |
| `c == "select"` 且有 `o`(选项) | 下拉框 |
| `c == "bcd"` 或 `key == "addr"` | 地址文本框（12 位 hex/BCD） |
| `key ∈ payload/data/content` | hex 报文多行框 |
| `key == "_time"` | 日期时间输入 |
| `key ∈ nodes/meters/relays/subs` | 地址列表文本框（逗号分隔） |
| 其他 | 普通文本框 |

表单提交 → 按字段 `key` 收集 `params` → 走 `/api/simcon/build` 预览 + `/api/simcon/step` 下发。

## 4. 验收

- [ ] 无数据单元 Fn 不再出现 JSON 文本框（如 01H 初始化、12H 路由控制）。
- [ ] 有字段 Fn 渲染为表单输入框（带单位），无"字段/语义|格式|字节"参考表格。
- [ ] 表单参数正确组装为业务键名，构帧预览与下发不回归。
- [ ] UI 对齐 tokens-v2 主题（深色/浅色均正常）。

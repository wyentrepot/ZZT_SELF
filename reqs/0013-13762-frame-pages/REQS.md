## 1. 背景与问题

现状核查（2026-08-31，基于 `libs/parser_lib/adapters/adapter_10376/metadata/afn_fn.json`）：

| 问题 | 证据 |
| --- | --- |
| **库不对称**：只建模了下行请求字段，上行响应字段几乎全部缺失 | 74 个 Fn 中 38 个字段为空；AFN=06H 全部 5 个 Fn 字段数=0；AFN=10H 的 F21/F31/F101/F112 等字段数=0 |
| **列表型响应无分页契约**：F2/F5/F6/F7 只有下行"起始序号+数量"，上行"总数量+本次数量+记录列表"未建模 | 无法支撑"查 1-16 → 得总数 32 → 续查 17-32"的自动遍历 |
| **主动上报无保存模型** | AFN=06H 五类上报（从节点信息/抄读数据/工况变动/设备类型/事件）全部未建模、未落库 |
| **页面按功能混排而非按 AFN 独立** | 截图所示的目标形态：每个 AFN 一个独立页面，响应以记录表格罗列 |

## 2. 设计原则（用户确认过的约束）

1. **每个 AFN 一个独立页面**，按 AFN 组织导航（00H～F1H 共 16 页）。
2. **分页查询双模式**：
   - 指定范围：用户输入起始序号 + 条数，单帧查询；
   - 自动全量：以响应中的"总数量"驱动循环下发（首帧查 1-N，得总数 T 后自动续查 N+1-2N … 直至取满 T），显示进度与断点。
3. **主动上报直接落库**：AFN=06H 各 Fn 上报数据入库保存，页面可回查历史。
4. **收发建库、页面索引**：帧定义（下行请求 + 上行响应 + 分页契约 + 记录模板）全部沉淀在协议库（扩展 `afn_fn.json` 及解析器），页面从库读取渲染，禁止页面硬编码帧结构。
5. 所有字段设计**以蒸馏文档 03 为准**；文档未蒸馏到的（如 10H F104）显式标注"待补"，不臆造。

## 3. 库扩展设计（afn_fn.json v2 契约）

现有 Fn 条目增加上行与列表语义：

```jsonc
{
  "no": "F2", "name": "从节点信息",
  "req":  { /* 现有 fields 迁移：下行请求字段 */ },
  "resp": { /* 新增：上行响应字段 */ 
    "fields": [ /* 头部字段 */ ],
    "list": {                      // 分页契约（可重复记录时才有）
      "total":   "从节点总数量",     // 总数字段名
      "count":   "本次应答数量",     // 本帧条数字段名
      "reqStart":"从节点起始序号",   // 下行起始序号字段名
      "reqCount":"从节点数量",      // 下行条数字段名
      "record":  [ /* 记录模板字段 */ ],
      "pageMax": 16                 // 单帧最大条数（协议约束）
    }
  },
  "pageMode": "both",   // manual=仅指定范围 / auto=仅自动 / both=双模式 / none
  "persist": false      // true=上报类入库
}
```

兼容策略：`fields` 保留为 req 的别名（旧页面不炸）；v2 消费方优先读 `req`/`resp`。

#### 上报与帧日志保留策略（2026-09-01 用户拍板）

- **三张表全部按天保存**（`day` 列 = YYYY-MM-DD）：`report_event` / `report_meter_data` / `frame_log`。
- **滚动保留最近 5 天**：每次写入（收发帧 / 上报）触发清理，删除早于「今天 − 4 天」的旧日数据；
  即第 6 天写入时，第 1 天（最旧一天）被自动清空，循环往复。`_REPORT_RETAIN_DAYS = 5`。
- 一天一份数据，三表同按 day 窗口同步过期（业务行与证据帧一并清理，不留悬挂引用）。

### 临时层（快照制，可清理）

> 理由：档案会增减、在网节点会变，查询结果不做长期档案表，只做**快照**。

| 表 | 说明 |
| --- | --- |
| `query_snapshot` | 一次查询/自动遍历 = 一个快照：id/AFN/Fn/时间/总数量/状态 |
| `query_snapshot_item` | 快照明细行（记录字段按 AFN/Fn 映射）；挂在 snapshot_id 下 |

- 页面默认展示**最新快照**；可切换历史快照对比组网变化。
- 清理策略：保留最近 N 个快照（默认 10）/ 手动清理，不做长期累积。

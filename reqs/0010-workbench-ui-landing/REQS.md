# REQS-0010：侦听台工作台 UI 落地（workbench-ui-landing）

> 状态：🚧 进行中（2026-08-30 立项）
> 设计基线：`docs/ui/` 六页静态高保真设计稿（`index.html` 为设计系统总览，含实现红线五条）
> 关联：ADR-9（报文追踪）、需求 0008（simcon AI 控制面）、需求 0009（追踪后端 G1-G4 已交付）

## 1. 背景与目标

`docs/ui/` 已建成六页设计稿：侦听台、模拟集中器（用户提供的 demo 原稿）、报文追踪、协议字典、场景脚本、设计总览。
后端能力全部就绪（追踪 API、simcon、场景编排、字典数据文件），但工作台现有 UI 与设计稿存在代差：
报文追踪无任何页面、协议字典无任何页面、侦听台无追踪入口、模拟集中器只是模块日志页里的页签。

本需求把设计稿落成工作台真实页面，分期推进；**本期（P1）只落地：报文追踪 + 协议字典**。

|------|------|------|

| P2 | 侦听台页改版：三列布局重排 + feature_hint 卡 + 追踪跳转（后端已就绪，纯前端） | 待启动 |

## 3. 本期验收标准（P1）

1. 工作台导航新增「辅助」分组，含「报文追踪」「协议字典」两页，iframe 保活与 hash 路由行为与现有页面一致。
2. 报文追踪页：
   - 特征表单（scope/frm_type/app_id/app_port/msg_seq/dst_tei/nid/channel/app_raw_contains + 响应策略开关）
     可提交 `POST /api/listener/traces`；回放模式同步渲染 summary 七项计数 + rounds（时间簇）+ flow 三段证据链 + proxy_graph；
   - live 模式注册后可轮询快照、停止（DELETE）；追踪列表加载既有 live 追踪；
   - 证据帧可钻取（`GET /api/logs/frames/{id}` 展示原始 hex/摘要）；
   - listener 子应用未挂载时整页给出降级提示（FR-6），不白屏。
3. 协议字典页：四本字典（698.45 OAD / 645-2007 DI / 1376.2 AFN-Fn / 事件规则）可切换、可搜索、条目详情含
   名称/数据类型/单位/换算/desc（纠错与实证注记高亮）/原始 JSON；数据全部来自仓库真实文件，不内置副本。
4. 遵守设计红线：协议数据等宽字体、语义状态色（inconclusive/警示用琥珀）、空态给引导、页面 no-cache。
5. 冒烟测试覆盖：/api/dict 各端点 200 且条数正确；两个页面 HTML 200 且带 no-cache 头。

## 4. 非目标（本期不做）

- 侦听台改版（P2）、场景脚本页（P3）、模拟集中器独立页（P4）、壳层主题统一（P5）。
- 字典条目的"被引用位置/帧命中数"统计（需额外索引查询，后续按需加）。
- 追踪特征表单的存档/复用（特征 JSON 手工复制即可）。

## 5. 工程约定（沿用仓库既有决策）

- 页面零构建、纯静态 HTML+JS，放 `apps/workbench/static/pages/<id>/`；API 用绝对路径 `fetch("/api/...")`（前缀代理转发）。
- no-cache 由 `shared/web_static.NoCacheHTMLStaticFiles` 统一保障（cec5931）；JS 改动以 `?v=` 版本参数强刷。
- 新后端端点挂在 workbench 应用（`apps/workbench/dict_api.py`，APIRouter），无 UI 依赖，CLI/AI 可复用。
- 串口独占：侦听与模拟集中器互斥使用串口，UI 需体现占用状态（本期追踪/字典页不涉串口，P4 落地时处理）。

# REQS-0035 — sim_meter 模拟电表（DL/T 645 从站：应答地址 / 查询时间 / 抄表 / 波特率热切换 / 重庆即装即采）

> 状态：✅ 已完成（v1.0，2026-09-28）
> 创建：2026-09-28
> 来源：用户口头需求——"工程有模拟集中器、有侦听台，没有模拟电表；补一个基本的模拟电表，
> 暴露接口可切波特率、重庆即装即采类型可改、默认 07 的 645 电表"
> 关联：libs/sim_concentrator（模拟集中器，模式参照）、libs/parser_lib/adapters/adapter_645（构帧/切帧复用）、
> 知识库 01_DLT645_帧格式 / 协议层100、102（即装即采）/ CCO实现逻辑 03 与底稿 02（固件读表口径）

## 1. 背景与问题

工程链路里"电表"这一环一直是真实表计或缺失：调试集中器 / CCO / 侦听台时，
没有可控的 645 从站可用——想验证"读地址→抄表→校时→改波特率"或重庆即装即采的
建档链路，只能上真机。工程内已有现成的 645 解析与构帧函数
（`parser_lib.adapters.adapter_645`），但从未被组装成从站模拟器。

## 2. 用户诉求（原话归纳）

把基本支持的电表功能做一下：应答地址、查询时间、抄表、重庆即装即采等；
里面有解析有构建函数，用起来；单独开发这个功能；暴露接口，可以切换波特率，
重庆即装即采的类型也可以更改，默认是 07 的 645 电表；不懂的核查知识库。

## 3. 目标（v1.0 已交付）

### BR-1 应答地址
- 645-2007：`13H` 广播读通信地址（地址域 FE×6）→ `93H` 回 6B 地址（不加 33H，
  对齐知识库示例）；`11H` 读 DI `04000401H`（CCO 固件读表地址口径，线上 `34 37 33 37`）；
  `15H` 写通信地址（+33H 口径优先，非法 BCD 时按原始字节兼容）。
- 645-1997：`01H` 读 DI `C032H`（固件线上 `65 F3`）；`06H` 写地址。

### BR-2 查询时间
- 读 `04000101H` 日期及周次（YYMMDDWW）/ `04000102H` 时间（hhmmss），实时取自表内时钟；
- `08H` 广播校时（地址域 99×6、数据域不加 33H、不应答）与 `14H` 写时间（DI+PA+密码+操作者+数据）
  均落到表内时钟（记录偏移，随系统时间走动）；97 模式对应 `05H`（且 `08H` 在 97 模式下
  是修改密码，不得当校时执行）。

### BR-3 抄表
- 默认数据集：正向有功总电能 `00010000H` + 费率 1~4（和=总，便于对账）、
  三相电压 `02010100/02010200/02010300`、三相电流 `02020100/02020200/02020300`、
  瞬时总有功功率 `0203FF00`；数据集可经接口改值；
- 兼容重庆分钟采集卡口径别名：`00000001H`→正向有功总电能、`04000100H`→总有功功率；
- 未知 DI → `D1H`+ERR02（无请求数据）；`12H` 读后续 → `D2H`+ERR02。

### BR-4 波特率切换（协议 + 接口双通道）
- 协议：`17H` 更改通信速率（国标口径），速率特征字单 bit 有效
  （b0=600…b5=9600、b6=19200、b7=38400），应答回显后由通道层**先回帧再热切换串口**；
  知识库 645 卡口径 `09H` 作为兼容别名（卡内控制码表与国标有偏差，实现以国标为准并双兼容）；
- 接口：CLI `--baud`、REST `POST /baud`、`POST /config`，打开状态下热切换
  （读线程跨重开存活，`loop://` 亦有测试覆盖）。

### BR-5 重庆即装即采（JZJC）
- 状态：enabled、device_type（4036 半字节拼接口径：0x10 表 / 0x11 物联表 / 0x12 导轨表 /
  0x13 直流表 / 0x26 / 0x27 / 0x28 量测开关 / 0x29 分布式电源接入单元）、descriptor、
  protocol_type（00H 透明 / 02H 645-2007 / 03H 698.45）、seq、下挂设备（≤32）；
- 类型切换联动预设描述符（DDZY/DTSU/DJS/LKT/DFDL/EVBC/EVCC，可显式覆盖）；
- 上送报文生成（应用层数据单元）：`sta`（Q/GDW 11612.43 事件类型 51 数据子域）与
  `afn06f7`（Q/GDW 1376.2 AFN=06H F7 上行数据单元）两种口径，结构对齐知识库
  协议层/100 卡 §2.2/§3；REST `POST /jzjc/report` 可生成并可选从串口发出。

### BR-6 接口暴露
- 库 API：`MeterBrain.handle_frame / handle_hex`（纯协议，不碰串口，永不抛异常）、
  `set_address / set_version / set_serial_params / set_register / set_clock / set_jzjc / build_jzjc_report`；
- 串口通道：`MeterSerialChannel`（serial_for_url，支持 COMx、/dev/ttyUSB\*、loop://）；
- REST：`create_simeter_app`（前缀 /api/simeter，可独立跑或挂载侦听台）；
- CLI：`python -m sim_meter serve / api / ports / demo`；
- 会话帧日志：`data/logs/simeter/sm-*.jsonl` + 内存镜像可查。

### BR-7 默认 07 版 645 电表
- `MeterBrain(version="2007")` 为默认；`"97"` 切 1997（控制码表、2B DI、97 固件口径
  +33H 数据域）；CLI `--version 07|97`、REST `POST /config {"version": ...}`。

## 4. 非目标（明确不做）

- 645 密码/权限校验（写操作按模拟器宽松处理）、`12H` 分帧续读、`1AH/1BH` 清零类；
- 698.45 从站模拟（即装即采里 03H 协议类型仅作为上报内容字段）；
- 1376.2 完整 06-F7 链路帧封装（由 sim_concentrator 侧组合，本模块产出应用层单元）；
- 挂载进 workbench AI 编排（后续按需接 ai_capability_service）。

# REQS-0016 — 上行 Fn 只读化（主动上报从库读取，禁下发构帧）

> 状态：🚧 进行中
> 创建：2026-09-01
> 关联：REQS-0013（帧库 + 上报落库）、REQS-0015（参数区表单化）

## 1. 背景与问题

用户 2026-09-01 反馈：simcon 页面选中 **06H F1（上报从节点信息，dir=上行）** 时，
仍显示「下发」按钮与「该命令无数据单元，直接下发即可」，点下发报
`构帧失败：未覆盖 Fn 0x06-F1`。

**根因**：06H 主动上报是**模块/路由主动推送**（无需轮询/下发），非下行命令。
UI 未区分方向，把上行 Fn 当成了下发命令。

## 2. 目标

1. **上行 Fn（dir=上行）只读化**：隐藏「下发」按钮与业务参数表单，改为提示「该命令为上行
   （主动上报/应答），数据从收发库读取，无需下发」。
2. **06H 主动上报**：强化「上报历史」入口（读 `report_event` / `report_meter_data`），
   展示从库读取的记录。
3. 下行/查询 Fn 行为不变。

## 3. 设计

- `selectFn` 判断 `f.dir === "上行"` → 走上行只读分支：
  - `#btnSend` 隐藏；`#parBody` 显示只读提示（不再渲染表单 / 无数据单元卡片）。
  - 06H：`#btnEvents`（上报历史）在响应表格区已可见，直接读 `/api/simcon/store/events`。
  - 00H 确认/否认：同为上行，走只读提示（其字段为应答位图，非下发参数）。
- 下行 / 查询 Fn：恢复 `#btnSend` 显示，走原有表单 / 无数据单元逻辑。

## 4. 验收

- [ ] 选中 06H F1~F5：无「下发」按钮、无「直接下发」误导文案；显示从库读取提示 + 上报历史入口。
- [ ] 选中 00H F1/F2：无「下发」按钮。
- [ ] 下行 Fn（如 03H-F6 / 05H-F4）仍可正常构帧预览与下发。
- [ ] 无数据单元下行 Fn（01H / 12H）仍显示「直接下发」+ 下发按钮。

## 5. 变更记录

- 2026-09-01 需求建立；根因 = UI 未按 dir 区分上下行，上行 Fn 被误当下发。

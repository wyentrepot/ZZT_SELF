# REQS-0011：工作台 UI 重设计 Demo（workbench-ui-redesign）

> 状态：🚧 进行中（2026-08-30 立项）
> 交付物：`ui-demo/workbench-ui-demo.html`（单文件，假数据，双击即开）
> 功能基线：**`ui-demo/功能清单.md`（9 页 + 外壳 / 94 项）—— 唯一基线，禁止凭印象设计**
> 关联：REQS-0010（UI 落地 P1-P4 已交付、P5 主题统一挂起待决策）

## 1. 背景与目标

现有工作台 UI 存在三类已确认痛点（用户勾选）：

| 痛点 | 表现 |
|------|------|
| 导航不直观 | 9 个页面平铺，无分组语义，找不到功能入口 |
| 信息密度低 / 空间浪费 | 大量留白，关键指标不突出，一屏信息量少 |
| 状态不清晰 | 状态靠文字区分，缺少稳定的语义色与图形化指示 |

v1 风格稿已产出且风格获用户认可（「你这个风格我还是挺喜欢的」），但**丢了实际功能**，
用户点名三处：

1. 模块日志没有**串口发送数据框**
2. 侦听台的**分钟采集分析页面**不见了
3. **NID 的锁定**不见了

用户确立的**工作方法（本需求强制遵守）**：

> 「具体落实到项目要以项目实际功能为主，动手前要把现有的 UI 界面带有的功能列出一个表格来，
> 按页面模块的分类进行。**然后做完之后要核对功能**」

即固定流程：**功能清单 → 设计 → 核对**。

## 2. 设计基线（用户已拍板）

| 项 | 决定 |
|------|------|
| 视觉基调 | **深色专业仪表盘**（保留深色，去掉渐变与重玻璃拟态） |
| Demo 范围 | **全套外壳 + 9 页骨架**（不是 8 页，场景脚本页必须存在） |
| 交付形态 | **单文件 HTML**，假数据，双击即开，零依赖 |
| 不动的痛点 | 操作流程太长（用户未勾选，本轮不重构流程） |

## 4. 本期验收标准（P1）

1. **功能零丢失**：`功能清单.md` 的 94 项逐条核对通过，产出核对表（不得只写"已完成"，
   需给出每项落在 Demo 哪个位置）。
2. **用户点名的三处缺失已补回**，并在 Demo 中可指认：
   - 模块日志 · 串口发送框（含自动补换行、Enter 发送 / Shift+Enter 换行、隐藏/显示）
   - 侦听台 · 分钟采集分析视图（查询条件 + 周期统计 + 周期上报详情）
   - 侦听台 · 全局 NID 筛选条（NID + 起止时间 + 应用筛选 + 条件摘要 + chips）
3. **9 个页面 + 外壳全部可达**，hash 路由支持深链 / 刷新 / 前进后退，页面命名与生产一致
   （「协议字典」非「报文字字典」、「工作台状态」非「维护」）。
4. **4 套主题可切换**（深蓝科技 / 暗色翡翠 / 炭黑灰金 / 靛蓝玻璃），配色取自生产
   `apps/workbench/static/tokens.css`，切换后状态栏与「工作台状态」页同步。
5. **静态校验通过**：JS 语法可 `new Function` 通过；无悬空 id 引用；
   导航定义与 `<section id="p-*">` 无差集；标签开闭平衡。
6. **inconclusive 为独立紫色相**（`#A371F7`），不复用 warn 琥珀色。

## 5. 非目标（本期不做）

- 不改动任何生产代码（`apps/`、`libs/`、`shared/`）。
- 不做后端联调，Demo 数据全部为确定性伪随机（LCG，seed=20260830），刷新结果一致。
- 不做移动端适配（仅实现 <860px 窄屏抽屉，对应清单 0.9）。
- 不重构操作流程（用户未勾选该痛点）。

## 6. 工程约定

- 产物：`ui-demo/workbench-ui-demo.html` 单文件；v1 风格稿保留为
  `ui-demo/workbench-ui-demo-v1-风格稿.html` 备查。
- 发现的生产代码缺陷**只在 Demo 中修正 + 记录**，本需求不改生产代码。已发现 1 处：
  `apps/workbench/static/tokens.css` 的 `.badge.inconclusive` 与 `.badge.run` 共用 warn 配色，
  仅靠 `opacity:0.85` 区分 —— inconclusive 是证据缺失（≠失败），应有独立色相。
- 静态校验手法（可复用）：node 提取内联 script → `new Function` 验语法 →
  正则比对 HTML id 与 JS `$('#id')` 引用找悬空 → 比对导航定义与 section 差集 → div 开闭平衡。

# 国网 HPLC 解析工具：任务交接需求与进度表

> 文档用途：用于项目交接。接手人员可先按“运行入口”启动工具，再按“当前问题”和“待提供资料”继续完善并发抄表帧解析。
>
> 更新时间：2026-08-01

## 1. 项目目标

将国网侦听台日志解析能力封装为本地 Windows 工具：

- 使用 `GwHPLCAnalysis.dll` 解析国网帧；
- 支持数百 MB 日志文件按流读取和建立索引；
- 网页端按页查看每一帧的轻量摘要；
- 点击具体帧后，再调用 DLL 展示完整解析过程；
- 为后续日志流接入预留“索引、分页、按需详情”的处理方式。

## 5. 运行入口

### 正式模式

运行根目录的 `启动解析工具.bat`：

1. 启动本地服务 `http://127.0.0.1:8765/`；
2. 在网页输入日志完整路径；
3. 点击“建立解析索引”；
4. 从左侧分页表中点击具体帧查看详情。

### 测试模式

运行根目录的 `启动解析工具-测试模式.bat`：

- 自动加载 `hplc_web/tests/data/gw_log_sample.txt`；
- 不访问用户的数百 MB 原始日志；
- 适合验证网页、分页、详情和启动流程。

### 关键服务接口

| 接口 | 用途 |
|---|---|
| `GET /api/version` | 查看 DLL 名称和版本 |
| `POST /api/parse` | 解析单帧 |
| `POST /api/logs/open` | 开始建立日志索引 |
| `GET /api/logs/status` | 查看索引进度 |
| `GET /api/logs/frames` | 分页读取帧摘要 |
| `GET /api/logs/frames/{id}` | 获取选中帧的完整解析 |

## 6. 当前已知问题

### 6.1 并发抄表帧解析仍不完整

当前 DLL 已能进入“终端并发抄表”相关分支，但真实报文中的 MPDU 字段仍需要和协议原文逐字段核对。重点关注：

- 应用层类型和业务类型的判定；
- 并发抄表数据单元的数量及循环结构；
- 每个数据单元的终端地址、对象标识、数据长度和数据值；
- 请求帧与响应帧之间的序列号、地址和业务关联；
- 长度字段、分片/拼接和校验字段的边界。

### 6.2 测试样本中存在 DLL 摘要异常

开发样本共 300 帧，索引不会丢弃异常帧；部分帧的 DLL 简单解析返回错误或不完整结果。异常帧仍保留原始十六进制内容，可以点击逐帧查看完整结果。

这类“解析异常”不能直接等同于“原始帧错误”，需要结合 MPDU 长度、帧类型和协议定义判断。

### 6.3 大文件使用边界

- 不要把完整日志粘贴到聊天中；
- 不要反复读取原始大文件做试验；
- 需要分析时先截取有限行数/有限字节的样本；
- 真实验收建议按时间段或帧序号做小范围抽样。

## 7. 并发抄表专项交接资料

接手人员继续修正前，优先获取以下资料：

| 资料 | 最低要求 | 用途 |
|---|---|---|
| 异常并发抄表原始帧 | 完整 `7E ... 7E` 十六进制帧 | 重现问题 |
| 请求/响应样本 | 至少一组，最好包含同一业务序列 | 判断交互关系 |
| MPDU 字段说明 | 字段偏移、长度、字节序、位域 | 修正解析偏移 |
| 预期解析结果 | 至少指出帧类型、地址、数据单元和业务值 | 做回归断言 |
| DLL 或旧工具结果 | 同一帧在原工具中的显示结果 | 对比兼容性 |
| 协议版本 | 使用的国网 4-2/4-3 版本或修订稿 | 防止版本差异 |
| 旧工具程序包 | `GwMixListener.exe` 及依赖库、语言资源（2025-06-29 版本） | 与原工具显示结果对比 |
| 原始报文文件 | `原始报文自动保存 - 2026-08-01.txt`（rar 内，约 265 MB） | 用真实报文核对并发抄表字段 |

最有价值的交接包是：一组完整请求帧 + 一组完整响应帧 + 旧工具解析截图/JSON + 对应 MPDU 字段表。

## 9. 交接后的建议顺序

1. 用测试模式确认网页和 DLL 版本正常；
2. 选取一组并发抄表请求/响应帧，保存为小样本；
3. 对照知识库中的数据链路层和应用层协议，标出 MPDU 字段偏移；
4. 在 DLL 解析分支增加针对该帧的回归测试；
5. 重新编译 DLL，使用网页右侧详情逐字段核对；
6. 最后再对真实日志做一次受控区间验收。

## 10. 当前结论

大文件索引、分页摘要、本地网页、DLL 调用和启动脚本已经形成可交接版本。当前唯一需要协议专项投入的核心问题是“终端并发抄表帧的 MPDU/应用层字段解析”，下一步应以真实异常帧和对应协议字段表为准，不建议继续盲猜偏移。
